# 去 AI 味 / 去短剧味

改用户给的 AI 中文。保原意与事实，不扩写、不换题、不编细节。

**输出**：只交改后正文。不复述任务、不点评、不列「改了什么」。

## 改稿顺序（必须按此执行）

```
① 题材分流  →  ② 去 AI 味  →  ③ 去短剧味  →  ④ 自检交稿
```

1. **先题材分流**：定主题材与目标气味，按该题材改结构/语气/信息摆法（见「第一步」）。未分流前，不动手去味。
2. **再去 AI 味**：在已定题材的稿子上，只扫并改 AI 形式信号（见「第二步」）。
3. **再去短剧味**：在去完 AI 味后，再扫并改短剧工业腔（见「第三步」）；悬疑/情感/日常加重，教程/资讯轻扫。
4. **自检后只交正文**。

禁止反过来：禁止先按通用去味清单整篇洗一遍，再补题材；禁止跳过题材直接「去 AI 味」。  
`小说/**` 且为悬疑/志怪/推理 → **主题材是悬疑**，不是「日常」；生活化笔法叠 `living-prose-novel`，仍走本 skill 二三步。

## 硬约束

1. **信息守恒**：终稿每个事实、数字、人名、因果都能在原文找到；缺材料不补。
2. **论断强度守恒**：「可能 / 通常 / 据说」不能升级成「一定 / 会」；主次关系不颠倒。
3. **最小改动**：只改命中的句；能删套话就删，不要整篇换腔表演「更像人」。
4. **指得出来再改**：每条规则都要能指到具体字句；指不出就别动。

## 第一步：题材分流

用户点名题材优先；未点名则从内容推断。定**一种**主改法后再往下走。

| 题材 | 目标气味 | 本步改什么 |
|------|----------|------------|
| **悬疑 / 志怪 / 推理** | 线索落地、气压稳 | 物证与场面推进；旁白不抢先揭底；忌段段反转 |
| 日常 / 生活纪事 | 口语、人情味 | 场面、物件、半截话；少总结 |
| 情感 / 亲密关系 | 克制、可接话 | 感受嵌进动作；为第三步重砍短剧味打底 |
| 小说虚构（非悬疑） | 生活化叙事 | 叠 `living-prose-novel`；否则「日常+情感」；**设定专名首次出现须人话讲清再简称** |
| 对白 / 对话 | 嘴里冒的 | 短、具体、可顶嘴；删主题句 |
| 观点 / 评论 / 博客 | 有判断、不演讲 | 判断在前；留论据，少演讲架势 |
| 教程 / 说明 / 技术 | 能照做 | 步骤清楚；删鸡汤壳 |
| 科普 | 好懂、不唬人 | 术语落地；收膨胀表述 |
| 职场 / 商务 / 汇报 | 把事说清 | 结论+事实；人话写事项 |
| 营销 / 种草 / 宣传 | 可信、不喊麦 | 具体卖点；收万能承诺 |
| 资讯 / 纪要 | 中性、好扫 | 保留要素；收情绪钩子 |

混搭：以**篇幅最大或用户指定**为主；对白段落单独按「对白」做本步。  
大纲或正文写明悬疑/志怪/推理，或路径如枯井、查案、搜证、伪死、起获等 → **优先定「悬疑」**，勿误分流成日常。

### 悬疑 / 志怪 / 推理

- **目标**：让人跟着查，不跟着被吓一跳营销；气压靠物证、规矩、闲话漏嘴，不靠旁白剧透。
- **线索守恒**：庚帖、铁链、药渣、红布、账本等物证原样保留；不合并掉关键伏笔，不提前用旁白点破答案。
- **微物证早放轻放**：裙子起皱、绳磨白、药渣、碎布味——出现时别强调「这很关键」；摊牌时再收回。
- **推进方式**：问→看→记→再问；人物「心里有数」写成薄册、问话、停顿，少写「他突然明白真相是…」。
- **留白合法**：可以不说破，但留白靠场面缺口（井绳新磨、死状开不出），不靠「他不知道的是」「命运般的」。
- **声音当线索写**：写方向、疏密、重复；用象声（咚、喀、嚓、沙沙）代替「闷 / 沉 / 一下接一下」；别解释「这说明有人在井下」。
- **忌短剧式悬疑**：禁止每段一个小反转、禁止「就在这时一切都变了」、禁止金句揭底对白连打。
- **志怪外壳**：怪力只作壳，内核仍是人事与规矩；「有没有妖怪」用具体见闻收束，不升华成主题演讲。
- **收束**：停在物证声响或一个小动作上（布包「咚」一声、抓住脉枕），不写判词感悟。
- **笔法**：`小说/**` 时叠 `living-prose-novel`（口语、场面、感官落地、象声词），**题材仍按本条**，走完二三步。

### 日常 / 生活纪事

- 用过日子的说法：语气词、省略、口头重复可以留一点；别写成作文。
- 感受靠动作和物件带（杯子、钥匙、冰箱灯），少「我感到一种…」。
- 段末不升华；吵完可以没和解金句，洗碗吃饭就行。
- 时间用具体点（「周三晚上」）优于「在那个特殊的时刻」（原文没有的日期不造）。

### 情感 / 亲密关系

- 冲突别当场清算成打脸；可以别扭、冷场、说半句。
- 「我爱你」类主题句能嵌进事里就嵌；嵌不了就删空话，留具体行为。
- 禁止心灵鸡汤收束（「爱是…」「成长是…」）。
- 本步只把语气收到「过日子」；眼神拳头、命运旁白等留给**第三步**集中砍。

### 小说虚构（非悬疑）

- 悬疑/志怪/推理 → **改走上面「悬疑」**，不要进本条。
- 生活流、情感向：`小说/**` 叠 `living-prose-novel`；叙事按「日常」，感情戏按「情感」，对白按「对白」。
- 旁白只交代时空动作；段末不升华。

### 对白 / 对话

- 一句一个意思；删答辩稿、删口号式对白。
- 能开口就别用旁白代说（「他表示自己其实…」→ 改成他说的话，若原文已有话）。
- 每人说话习惯略有差别即可，不要每句都「金句反击」。

### 观点 / 评论 / 博客

- 开头直接亮判断，少钩子、少痛点承诺三段式。
- 保留原文里的例子与限定词；不把随笔改成演讲稿，也不改成无态度的说明书。
- 翻案腔、段末金句等具体句式留给**第二步**。

### 教程 / 说明 / 技术

- 按「做什么 → 怎么做 → 注意什么」理顺；步骤原有序号可留。
- 删「赋能」「轻松掌握」「只需三步走向成功」；动词用「打开 / 填写 / 运行」。
- 代码、命令、路径、报错原文不动；只改包裹它们的说明腔。

### 科普

- 一个概念一句人话；类比点到为止，禁止比喻链铺满。
- 不确定就保留「可能 / 目前认为」。
- 危险提示、就医/专业建议等原文有的硬提示不得删（尤其唯一一句兜底）。

### 职场 / 商务 / 汇报

- 结构优先：结论在前，再依据、再风险/下一步（原文有则保留顺序逻辑）。
- 改成「谁、做什么、截止何时」；不写鼓舞士气段。

### 营销 / 种草 / 宣传

- 卖点落到可感知处（原文有的功能、价格、场景）；删「颠覆」「必入」「你值得」。
- 少感叹号、少三段排比承诺；证言无来源则改中性或删。

### 资讯 / 纪要

- 保留时间、人物、事件、数字；删情绪形容词与悬念标题腔。
- 一句一事；不添评论。

**本步结束标准**：题材对了、结构/语气对了。然后才进入第二步。

## 第二步：去 AI 味（形式信号）

仅在第一步完成后执行。按题材已定的气味改，不借去味另换一套腔。

1. **翻案腔**：高密度「不是 A，而是 B」「你以为…其实…」「这不仅是…更是…」→ 正面直接说判断。
2. **提示语冒号**：「一句话总结：」「核心是：」「原因有两个：」→ 删提示语，直接写。
3. **起手套**：「说白了」「说穿了」「先说结论」「值得注意的是」「不可否认」→ 删掉起手，直接给内容。
4. **话题壳 /「当…时」**：「对于…来说」「在…的背景下」→ 改成主语开门见山（时间关系会糊的保留）。
5. **句首路标扎堆**：相邻多段都以「然而 / 因此 / 此外 / 同时」开头 → 挪到句中或删。
6. **顿号罗列过密**：一分句里三项以上堆名词 → 能概括就概括（配置清单除外）。
7. **相邻句同骨架**：连着几句逗号位置、收尾一样 → 打散一句或换语序，不删信息。
8. **同义词轮换**：同一概念轮换「优化 / 提升 / 增强」→ 统一回原文用词。
9. **衔接过顺**：段段用「这也解释了为什么」「从这个角度看」「一个自然的追问是」扣住 → 允许硬切。
10. **破折号过密**：约每千字超过 2 个再优先处理；插入解释、人物语气的可留。
11. **段末金句 / 祝福收束**：段尾抛对仗口号、人生道理、「希望这对你有帮助」→ 删，停在事实或动作上。
12. **华美空洞**：开篇堆环境、一句话三个以上形容词、华丽但推不动信息 → 做减法，留能办事的一句。
13. **意义膨胀 / 模糊归因**：「标志着」「奠定基础」；「专家认为」「有报告显示」却无出处 → 删帽子，或改成原文已有的具体说法。
14. **替读者立靶再打**：先替读者说一句蠢话再纠正 → 只处理原文真有的误解。
15. **感官评语冒充描写**：「闷，一下接一下」「很有分量」「细长的影子」→ 换成象声、动作、可摸的细节（咚咚咚；指节发白；影子拖在石板上）。

### 不要当 AI 味去改（改了更假）

- 正常设问、问句小标题
- 「首先 / 其次 / 最后」、序数小标题（单独出现不算病）
- 为「长短参差」把通顺句剁碎
- 单靠禁用「赋能 / 闭环 / 抓手」词表
- 比喻本身（只改工整到失真、一路铺满的比喻链）
- 没有依据就「加入个人经历 / 具体数字」来扮人味

**本步结束标准**：AI 套话/翻案/金句清掉，题材气味仍在。然后进入第三步。

## 第三步：去短剧味（叙事/情绪工业化）

仅在第二步完成后执行。强度随题材：**悬疑 / 情感 / 日常 / 对白加重**；教程 / 科普 / 职场 / 资讯 **轻扫**（有钩子故事腔再砍）。

1. **别连续高潮**：禁止段段转折、句句抓马、每段一个小反转；悬疑的紧绷靠线索叠加，不靠每段翻盘。
2. **别人设贴标签不成长**：删掉反复盖章的身份台词（「我可是…」「你算什么」）；人物用具体事推进，不靠口头标签。
3. **别快意恩仇、黑白秒判**：少「打脸 / 碾压 / 当场跪」式兑现；冲突可以留着别当场清算。
4. **别眼神拳头专场**：少「眼神暗了 / 坚定」「拳头攥紧」「泪水夺眶」；改成物件、动作、半句能接的话。
5. **别旁白剧透 / 命运旁白**：「他不知道的是…」「命运般的…」「就在这时，一切都变了」→ 删或改成当场可见的事。（悬疑尤忌用旁白提前泄底。）
6. **别舞台腔对白**：「你到底把我当什么」「从今以后一刀两断」「我回来了」式金句反击（戏仿除外）→ 改成短、具体、可接话。
7. **别情绪瞬切 + 配乐词**：无垫的「心猛地一沉」「这一刻」「永远」「再也」堆叠 → 用一件小事托住反应。
8. **信息差分题材**：
   - 非悬疑：少「读者知道角色不知道」的故弄玄虚；该说清的说清。
   - **悬疑**：允许线索式留白；禁止旁白剧透式信息差；答案用搜证、问话、起获兑现，不用金句宣布。
9. **别套路梗重组**：同一羞辱→逆袭→再羞辱循环，只换词不换事 → 合并重复虐点，留一条清楚的线。
10. **营销里的短剧广告腔**：「直到有一天…命运转折」→ 回到具体卖点（仍服从第一步题材）。

## 正面（题材对了再去味后的气味）

悬疑：
```
井绳不旧，绳上有新磨白的印子。井早没水了，却常有人往下吊东西。
「既死了，请开一张死状。」曹先生脸色煞白。少主说车马都备好了。
红布包吊上来，撞到砖缝，咚，咚，咚。他记得阿禾抓脉枕，指节发白。
```

日常：
```
牙膏挤多了，两人都笑了一下，也没再提刚才吵的那句。
「行，那今晚你洗碗。」她说完就去拿围裙，他嗯了一声，把椅子拉近了点。
```

观点 / 职场：
```
效率的关键在流程。团队大了以后，管理者更需要把流程理清，并定期复盘。
结论：本周先上登录，支付放到下个迭代；风险是第三方回调还不稳定。
```

教程：
```
1. 打开设置 → 开发者选项。
2. 打开「USB 调试」，手机上点允许。
3. 电脑执行 adb devices，能看到设备号再继续。
```

## 工作方式

- 用户点某段 → 只改该段及同类句（仍走 题材→AI味→短剧味）。
- 用户说全文改 / 整篇去味 → 通读后一次性交改后全文。
- 用户说「按悬疑改」「按日常改」「按教程改」等 → 第一步强制该题材，再走二三步。
- `小说/**` 悬疑/志怪 → 题材「悬疑」+ 笔法 `living-prose-novel`，二三步照走。
- 非悬疑小说且要生活化笔法 → 叠 `living-prose-novel`。
