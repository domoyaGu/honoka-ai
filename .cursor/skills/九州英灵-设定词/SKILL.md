# 九州英灵 · 设定词统一

**硬规则**：专名先定一种叫法；**同一段不要换着花名**骂同一事物。  
第一次出现用人话讲清 → 再只用主词。笔法跟 `living-prose-novel`。

**非必要不谜语人**：该让读者懂的设定与状态，先用人话说明白，再挂编制名；禁止「半控。」「油污。」「感岔。」这类硬砸短词开场。与 `living-prose-novel` 第 15 条一致。

---

## 1. 宿主三态

| 主词 | 含义 | 战场 |
|------|------|------|
| **宿主** | 总称：周身黑气、被夺控的身子 | 人打宿主 |
| **半控** | 原魂还在、被按住 | 优先驱离黑气救人（可说「剥气」） |
| **空壳** | 原魂已无 | 可击毙 |

**废作编制名**：行尸、机器、光秃秃的「壳」（「空壳」除外）。

---

## 2. 我方英灵侧

| 主词 | 含义 | 说明 |
|------|------|------|
| **英灵** | 应召后显在召唤者身旁的战力（主词） | 正文默认说「英灵」 |
| **应召** | 动词/技术：把英灵召出来 | 「齐砺应召」「陆铭应召周公」 |
| **召唤者** | 绑定并供锚的活人 | |
| **名核** | 该英灵在名录里的唯一核；熄=永灭不能再召 | |
| **名沉** | 被记住的强度；应召吃名沉 | 勿与名核混为一谈 |
| **名录署** | 匹配、独占名核的机构 | |
| **名录共鸣** | 华国应召技术路线 | 禁写替身/JOJO/Stand |
| **周公** | 陆铭绑定的唯一英灵；**不当刀使** | 应召后开**感应**；编制锁定单魂 |
| **感应** | 陆铭经周公碰魂层、辨潮向/真假/半控空壳/黑史魂脏名压 | **不是**自带超人听力，**不是**靠闻气味 |
| **感应官** | 军中编制岗名（陆铭） | 经周公开感应、报坐标；手感对标「领路人」扫危险/指方向，岗名不叫领路 |
| **永灭** | 名核熄；我方召唤者重伤不醒 | |

**禁止**：同段「应召体 / 英灵 / 影 / 替身」轮换指同一个。  
用「应召体」仅当强调「刚显形的技术态」且同段不再换词；**优先统一为英灵**。  
**废词**：听影、耳机（指人）、靠闻、鼻子尖当感知。

## 3. 敌方魂侧

| 主词 | 含义 |
|------|------|
| **黑气** | 夺控/污染的可见标志 |
| **魂潮** | 敌方潮涌总称 |
| **杂潮** | 无组织的低阶潮 |
| **残潮** | 战后渗漏小股 |
| **灰膜** | 无主低阶魂壳炮灰（首次可括注「低阶魂壳」） |
| **黑史魂** | 被污染的外国历史强魂 |
| **脏名压** | 陆铭经周公感应到的黑史魂污染感（勿写成闻油污） |
| **巢** | 敌方据点/井 |
| **分芽** | 巢/母体从缝里伸出的一小截活的 |
| **母体** | 终局灾核 |
| **牧场** | 沦陷区圈养活人的状态；**牧场民**=未附身被抽税的人 |

**高巢具名**（固定）：潮王座、帝冠巢等——用全名，勿一轮「大巢」一轮具名唬人。

---

## 4. 闭关与江防

| 主词 | 含义 |
|------|------|
| **魂路闭关** | 政策总称（街口可简称「闭关」） |
| **魂障** | 闭关铺开的魂层封锁网 |

**禁止**：同段「闭关网 / 魂障 / 闭关令」三词乱跳指同一层物理网——物理层统一叫**魂障**，政策叫**魂路闭关**。

## 5. 军政文宣

| 主词 | 含义 |
|------|------|
| **点名定心** | 广播我方英灵到岗，全国松气 |
| **敌方点名** | 通报黑史魂现身 |
| **双点名** | 敌我各报一名对位 |
| **战情档** | 蓝/黄/橙/红/黑 |
| **编制** | 军中岗位与名核归属（勿与「名沉」混） |
| **感岔** | 感应方向/真假报错（旧「听岔」废） |

## 6. 战场分工（提醒）

- **人** → 宿主（剥气救半控 / 击毙空壳）  
- **英灵** → 灰膜、魂潮、黑史魂、巢、分芽  
- **陆铭 + 周公** → 感应官岗、感应、报坐标；卷一不拧、周公不砍人

## 正文结构（叠用 · 详见大纲2 / 九州英灵-正文 rule）

- **禁废话，不禁篇幅**；章数不限；单章写充实。
- **前期单线为主，侧线按需开章**（死跟红档）。
- **禁写对标梗名**：全明星、JOJO、替身、Stand、领路人、独自升级等。
