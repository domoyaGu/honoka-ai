# 三遍勾选表（逻辑自检）

逐项默认为待查；命中则写入报告，写清证据。未命中勾「通过」。

---

## 第 1 遍 · 全书

### 剧情逻辑

- [ ] 主线「因 → 果」链条完整，无跳步、无事后发明的关键因
- [ ] 同一事件在不同章节叙述不互相否定（时间、谁在场、结果）
- [ ] 冲突升级有压力来源，不是为打而打
- [ ] 多线汇合点合理（人物如何赶到、为何同场）
- [ ] 反派/对立面有可持续动机，不是纯工具人搅局（群像书：每个镜头方也要有当场要事）

### 设定逻辑

- [ ] 世界硬规则（能力、代价、禁忌、胜负条件）前后一致
- [ ] 无「前文说不能、后文随便能」或反过来
- [ ] 机构、地理、势力关系不自打脸
- [ ] 新设定出现有来源，不是为救场临时加挂
- [ ] 与现行大纲/专名表冲突处已标出

### 人物与情感走向

- [ ] 主要人物有可辨认的起点状态与终点变化
- [ ] 关系线（信任/对立/羁绊）有推进或明确停滞理由
- [ ] 无无铺垫的性格大翻转；有翻转则有压力事件支撑
- [ ] 情感高潮有前文积累，不是突然喊口号
- [ ] 配角命运与主线有勾连，死/离/退场有回声或功能

### 开头

- [ ] 开篇建立「这世界正在发生什么」与「读者该跟谁」
- [ ] 开篇抛出的悬念/承诺，全书有回应路径（已写部分能看见方向）
- [ ] 开篇信息量不导致后文必须靠遗忘才能推进

### 结局 / 当前终点

- [ ] 已写结局或卷末：是否兑现开篇与中段承诺
- [ ] 关键伏笔有回收或明确「留待后卷」且不误导为已死线
- [ ] 结局情绪落点与人物弧光匹配（惨胜/残缺/开新等说得通）
- [ ] 无「靠新规则一夜翻盘」而未付前文代价

### 时间线与连续性

- [ ] 昼夜、战役间隔、伤愈、路程耗时大体合理
- [ ] 道具/情报/伤势跨章连续，无凭空恢复或消失

## 第 2 遍 · 按卷（每卷一张）

**卷名：** ________

### 卷任务

- [ ] 本卷在全书中的叙事任务清楚（对照目录/大纲）
- [ ] 本卷主冲突有开有收或有明确移交下一卷的钩
- [ ] 卷内支线未挤爆主线因果

### 卷衔接

- [ ] 卷首状态接上上卷末（人物、局势、未决问题）
- [ ] 卷末钩子服务全书方向，非硬截或重复上钩

### 卷内人物情感

- [ ] 本卷人物关系有可感变化或稳定的理由
- [ ] 情绪节奏：压 → 放 / 胜 → 代价，不单线平推
- [ ] 镜头切群像时，切走前后情绪不断层

### 卷内设定

- [ ] 本卷新规则与全书一致
- [ ] 本卷战斗/制度结算方式与前文代价一致

### 卷结构

- [ ] 卷中段无大段空转（有场面无推进）
- [ ] 卷高潮位置合理，不提前泄力也不拖到无气

## 第 3 遍 · 按章（每章过一遍）

**章：** ________

### 章功能

- [ ] 这章推进了情节、人物或信息中的至少一项
- [ ] 删掉本章后，后文某因果会断 → 证明本章必要；否则标「可删/可并」

### 章内因果

- [ ] 人物行动有当场动机
- [ ] 行动导致的后果在章内或章末可见（或明确延期并记账）
- [ ] 对话/决策不与人物已知信息矛盾（除非故意说谎且可辨）

### 情感与人物

- [ ] 章首情绪接章末上一章
- [ ] 当章情绪转折有触发事件
- [ ] 关系互动符合已建立的亲疏与立场

### 信息与可读因果

- [ ] 读者理解当章因果所需的关键信息已给出（含设定人话托住）
- [ ] 无靠读者「猜设定」才能懂的胜负/生死
- [ ] 该隐瞒的未提前泄；该明说的未谜语化到逻辑不通

### 章衔接

- [ ] 人物位置、时间、随身物、伤势与邻章连续
- [ ] 章末落点不是简单重复上章末
- [ ] 下章所需的钩或状态已埋（若本章声称要接下文）

### 章内节奏（逻辑向）

- [ ] 无同一信息用三次不同说法却无新压力
- [ ] 战斗/会议有胜负条件，不是打完发现什么都没变又无解释
