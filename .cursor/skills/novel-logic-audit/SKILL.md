# 小说逻辑自检（三遍筛查）

**只查不改**。文笔/去 AI 味归 `living-prose-novel`；本书专名归该书设定词 skill（如有）。  
本 skill 管：剧情因果、设定自洽、人物情感走向、开头承诺、结局兑现、线索收放。

详细勾选表见 [checklists.md](checklists.md)；报告骨架见 [report-template.md](report-template.md)。

## 硬规则

1. **必须跑满三遍**，顺序固定：①全书 → ②按卷 → ③按章。禁止只抽几章就交差。
2. **只出问题清单**，默认不改正文。用户明确说「按报告改」后再改；改完用本 skill **再跑一轮**（循环）。
3. **证据要落地**：每条问题写清「位置（卷/章/段落线索）+ 矛盾双方 + 为何不通」。禁止空喊「逻辑有问题」。
4. **先读大纲再读正文**：有 `大纲*.md` / 卷内 `目录.txt` 先读；正文与大纲冲突时，两条都记，标明「正文 vs 大纲」。
5. **有专名表就叠用**：如 `九州英灵-设定词`——设定矛盾优先对照专名表。
6. **不混文笔项**：电报蹦词、排比、金句等不进本报告（除非已导致读者看不懂因果）。

## 输入与范围

用户未指定书名时，问清路径（如 `小说/九州英灵，随我收复河山/`）。

盘点文件（按实际存在读取）：

| 层级 | 典型路径 |
|------|----------|
| 大纲 | `小说/<书>/大纲.md`、`大纲2-*.md`（废稿标废，勿当现行设定） |
| 卷 | `小说/<书>/卷*-*/`，内含 `目录.txt` + `第NN章-*.txt` |
| 散章 | 书根下 `第NN章.txt`（并入最近一卷或单独「未归卷」） |
| 旧报告 | 同目录 `逻辑自检-*.md`（续查时先看未闭环项） |

单卷/单章任务：仍跑三遍，但 ①全书改为「当前已有正文的整体」；②只查目标卷；③只查目标章（前后章各读一章做衔接）。

## 工作流（循环）

```
盘点文件 → 第1遍全书 → 第2遍逐卷 → 第3遍逐章
       → 去重合并 → 落盘报告 →（用户要改则改）→ 再跑本 skill
```

### 第 1 遍：全书

通读全部已生成正文 + 现行大纲，只抓**跨全书**问题。勾选 `checklists.md`「全书」整表。

至少覆盖：

- 主线因果链是否断、是否自相矛盾
- 世界观规则是否前后打架（能力、代价、禁忌、胜负条件）
- 主要人物弧光：起点欲望/恐惧 → 中段压力 → 终点是否赚到或赔掉，有没有无因突变
- 开篇向读者承诺了什么；全书是否在兑
- 结局（或当前卷末）是否回收关键伏笔；有没有开了不收、收了没铺
- 时间线、地理、势力关系总表是否自洽
- 多线并行时：谁在干什么、汇合点是否合理

本遍产出：`全书问题[]`（可暂记，末尾合并）。

### 第 2 遍：按卷

对每一卷（有 `目录.txt` 的目录优先）顺序检查。勾选「按卷」表。

至少覆盖：

- 本卷叙事任务（对照卷目录/大纲）是否完成
- 卷首是否接得上上卷/开篇；卷末钩子是否服务于全书而非硬截
- 本卷人物关系与情感进度：有没有该升温却平、该破却拖、情绪跳档
- 本卷新设定是否与全书规则冲突；本卷是否偷偷改规则
- 配角戏份：有没有抢戏却无功能，或功能角色无动机
- 卷内主线/支线比重：支线是否挤爆主线因果

每卷产出：`卷问题[卷名]`。

### 第 3 遍：按章

按阅读顺序逐章。勾选「按章」表。长书可分批，但**不得跳章**；每批结尾记下「已查到第几章」。

至少覆盖：

- 章目标：这章解决/推进了什么；删掉是否影响因果
- 章内因果：动机 → 行动 → 后果是否接得上
- 人物当章情绪是否接上一章末状态；有没有无过渡的性格翻转
- 信息分配：该让读者懂的是否懂；不该剧透的是否提前泄；专名是否未解释就当读者已知（导致逻辑读不通）
- 章末落点：是否空转、重复上章、或跳戏
- 与相邻章：人物位置、伤势、道具、时间是否连续

每章至少扫一遍清单；无问题可记「通过」，有问题必须条目化。

### 合并与落盘

1. 三遍问题去重：同一根因只留一条，注明「全书/卷X/章Y 均可见」。
2. 定级：
   - **P0** 设定或主线自相矛盾、人物无因翻脸、结局打脸前文硬规则
   - **P1** 伏笔未收、卷间断裂、情感跳档、动机薄弱但可补
   - **P2** 节奏空转、说明不足、可改可不改的小疙瘩
3. 写入：`小说/<书名>/逻辑自检-YYYYMMDD.md`（模板见 report-template.md）。
4. 回复用户：先给 **P0/P1 摘要**（条数 + 最重的 3～5 条），再给报告路径。勿贴全书复述。

### 循环

| 用户说 | 做法 |
|--------|------|
| 只检查 / 通读找漏洞 | 三遍 → 报告 → 停 |
| 按报告改 | 按优先级改正文（叠 `living-prose-novel`）→ **再跑本 skill** → 更新报告「复检」节 |
| 再查一遍 | 对照旧报告，先核闭环项，再全量或增量三遍 |

## 禁止

- 没跑完三遍就给「整体还行」
- 用文笔偏好冒充逻辑问题
- 改大纲废稿当现行设定
- 只凭记忆不打开正文文件
