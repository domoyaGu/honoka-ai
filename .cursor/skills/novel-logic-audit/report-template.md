# 逻辑自检报告模板

落盘路径：`小说/<书名>/逻辑自检-YYYYMMDD.md`  
复检同一天可加后缀 `-复检2`。

```markdown
# 逻辑自检 · <书名>

- 日期：YYYY-MM-DD
- 范围：全书已生成正文 / 仅卷X / 第aa–bb章
- 对照：现行大纲路径；专名 skill（如有）
- 轮次：首检 | 复检（相对报告：……）
- 三遍状态：全书 ✅ / 卷 ✅（列出卷名）/ 章 ✅（第01–NN）

## 摘要

- P0：N 条
- P1：N 条
- P2：N 条
- 一句话结论：……

## P0（必须先处理）

### P0-1 <短标题>
- 层级：全书 | 卷·卷名 | 章·第NN章
- 位置：文件路径 + 情节锚点（谁在干什么时）
- 矛盾：A（前文……）vs B（后文……）
- 影响：主线 / 设定 / 人物 / 开头承诺 / 结局
- 建议方向：（只点改法类型，不直接改文除非用户要求）
- 状态：开放 | 已改待复检 | 闭环

## P1

### P1-1 …
（字段同 P0）

## P2

### P2-1 …
（字段同 P0）

## 按遍备忘（可选，问题多时保留）

### 第1遍全书
- 通过项摘要 / 记账伏笔列表

### 第2遍按卷
- 卷一：……
- 卷二：……

### 第3遍按章
- 仅列有问题的章号；通过章可写「第01–05 通过」

## 伏笔账（全书维护）

| 伏笔 | 埋设位置 | 预期回收 | 现状（未收/已收/作废） |
|------|----------|----------|------------------------|
|      |          |          |                        |

## 人物情感弧（主要人物）

| 人物 | 起点 | 当前 | 目标终点 | 断裂风险 |
|------|------|------|----------|----------|
|      |      |      |          |          |

## 复检记录

| 轮次 | 日期 | 关闭 | 新开 | 备注 |
|------|------|------|------|------|
| 1    |      |      |      |      |
```
