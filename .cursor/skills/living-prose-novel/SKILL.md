# 生活化小说笔法（去 AI 味）

改写或新写中文小说时，**严格按本 skill**。目标：读起来像人过日子说话，不像范文总结。

## 硬规则

1. **话捋直、说完整**：旁白和对白都把意思说清楚；能一口气说完的，写成带逗号的口语长句或完整短句，**禁止「句号雨」**，也**禁止电报式蹦词**（两个字、三个字、四个字一截一截甩：「退。」「够。」「看。」「短。你听我的——」）。人物可以少言，但开口就要让读者听懂他在说什么。
2. **别排比、别对仗腔**：禁止一不小心排比、对仗、口号并列（「人还在，巢还接得上」「催就催，E级有什么好复的」这类半截对仗也要改成人话捋直说）。禁止段末金句、人生道理收束；收在物件、动作或一声响上。
3. **别「先…后…再…」总结**：禁止把领悟排成步骤或方法论（「先问自己，再开口，累完还能……」）。
4. **能开口就别转述**：人物心里清楚、当场该说的话，写成对白；禁止旁白代说「他说要……」「他明白……」「原来……」。
5. **意思嵌在场面里**：用动作、对话、物件带出感受；不另加抽象点评。
6. **对白要像嘴里冒的**：口语、具体、可接话；不要像答辩稿或心灵鸡汤。**「像人说话」≠「越短越好」**——宁可多半句把因果说清，也不要酷得让人猜。
7. **旁白只干脏活**：交代时间地点动作即可；不替读者提炼主题。
8. **展示，别讲述**：少写「他很饿 / 很怕 / 很闷」；写饭粒、叩桌、「咕」地咽下去、喉结移动（阿城《棋王》路子）。
9. **感官要落地**：形、色、声、味、触能写则写；别只用眼睛，也别堆「华丽的舞蹈」这类大词冒充细节。
10. **声音写成声，别写成评语**：禁止「闷，一下接一下」「沉闷地响起」这类抽象节奏；能用象声就用（咚、喀、嚓、咕、沙沙、橐橐）；写清从哪来、疏密如何，解释留给后文。
11. **细节要有用**：选决定性细节（服务人物/线索），不当事物巨细的室内设计师；白描抓一个小动作或一件道具即可。
12. **设定词先讲清再简称**：世界观专名（分芽、名沉、续名、试名牌等）**第一次在正文出现时**，必须让读者先懂它是什么——用场面、物件或嘴里一句人话落地；**讲清之后**才许反复甩短名。禁止假定「直接扔名词读者也看得懂」。顺序是：**解释清楚 → 再简化成称呼**，不是先甩黑话再懒得解释。
13. **背景先让人站稳**：章首或关键场面不要一上来堆专有名词、等级缩写、编制黑话。先用人话交代这世界眼下在发生什么、人物在干什么；需要科普时，用解说、广播、家人问话等自然嘴把话说全，禁止「名词顿号串烧」。
14. **关系、因果、情感写明**：英灵与召唤者什么关系、为何应召、战死/续名怎么接上、历史人物对家国的心——该让读者懂的，用对白或场面直接写清，禁止点到为止留谜语（「刺的是名」「投影碎白」这类读者要猜的写法一律改成可见可懂的过程）。爱国/痛惜等情绪靠人物嘴里的完整话和具体得失落地，不靠旁白喊口号，也不靠两字半截话装沉。
15. **非必要不谜语人（硬）**：该让读者立刻懂的背景、因果、称呼、战场状态，**用人话直接说**；禁止靠酷短句、黑话堆砌、半截暗示让人猜。编制专名可以出现，但**须同句或邻句用大白话托住**（例：先说「人还困在身子里，还能救」，需要时再点「半控」）。**例外**：人物故意隐瞒、说谎、对内黑话且读者已懂——其余默认直说。开篇与关键设定落地处，宁可多两句说白，也不要谜语开场。

## 反面（禁止）

```
「够。」「看。」「退。」「知道。」「短。你听我的——出巢，别回头许愿，别答话。」
催就催，E级有什么好复的。人还在，巢还接得上，他们爱看屏幕。
然后灰膜的牙缝对准名录上的「岳飞」两字，根丝刺的是名。投影碎白。
沈承岳，S级，英灵岳飞，中原失土——公文写汴京故土巡区——总攻倒计时。
「半控。」「空壳才是机器。」「油污。」「听岔。」——读者还没被告知这些词是什么。
北岸黑。闭关。牧场。耳机到了。——名词蹦豆，像谜语。
没什么仪式感，就是过日子。
闹的风光，收场的可靠。可靠很少有人记在心上，出了事却先想到你。
他说要跟你在一块，不是凑合，是自己选的。选了就免不了麻烦，麻烦他认。以前太会躲，躲到最后只剩自己一个人正确，正确有什么意思。
先问问自己到底想怎样，再开口。累是累，可累完还能并肩坐着吃饭，不用谁先演优秀。
装太久人会丢。找回来有时就靠一句反复说：我想要。
这不是什么逆袭神话，不过是一个曾经很会懂事的人，一点点学会在场。
日子像做卷子，卷子上没有爱人，只有对错。
在乎不等于认栽。
布袋撞井壁，闷，一下接一下；那一声很有分量。
非常规个体——分芽特征，母体侧——
广播里还爱补一句：母体不会整具钻进社区，她吃井、渗漏、分芽。
```

## 正面（照这个气味写）

```
何倩挤牙膏挤多了，他笑，她也笑，普通的日子也在笑。
小杰看着他们，鼻子忽然一酸。他没哭出来，只伸手握住何倩还带着水的手，那手凉凉的，他攥了一下。
许杰说：「跟你在一起是我自己选的，我记得，你不是麻烦，以前我只会逃避，最后只剩别人的一句我没做错，谁都讨好了，唯独没有自己选过。」
许杰夹了块菜，想了想，说：「只要能跟你坐着一块吃顿饭就行，好像不用听话懂事也能做到。」
回家路上雪很薄，旧路还在。他把她的手揣进同一只口袋，口袋不大，刚好两只手。
一粒干缩了的饭粒儿轻轻跳着。他放进嘴里，腮上立刻显出筋络，终于嚼完，和着口水，「咕」地一声咽下去。
红布包吊上来，撞到井壁，咚，又咚，再咚；阿禾抓住脉枕，指节发白。
「母体进不了城，会从巢缝里伸出一小截活的来吸——编制叫分芽。」灰膜半人高，细牙一圈，根丝扎地；后文再只说「分芽」即可。
陆晚说：「北岸还是黑的。灾是国外先闹出来的，它们一块地盘一块地盘圈住人养着；江南还能开门，靠封锁，也靠后来能站在人身边打仗的英灵。」
「人还困在身子里，偶尔挣一下，这种还能救；人已经没了、只剩身子在动的，就救不回来了。」
「先压住了，撑不了多久。你听清楚：立刻出巢，听见它说话别接话，也别回头许愿。接了就会被它记住。」
灰膜不理刀，牙缝抬起来，对着肩后名录投影里「岳飞」两个字；根丝不扎人的肉，直直扎进那两个字里。字裂开、白掉，影子跟着散成白雾。
「我是岳家后人沈承岳。岳飞的名字我续上了——人记得我，就还记得他。中原失土他当年没拿全的，今晚已经拿回大半……剩下的疆土，交给后来的人。」
```

## 改稿自检（每段过一遍）

- [ ] 有没有电报式蹦词（两三个字就句号）？意思说全了没有？
- [ ] 有没有短句排比、对仗腔、段末金句？
- [ ] 有没有「先/后/再」式领悟清单？
- [ ] 本该出口的话，是不是被「他说／他明白／原来」吞掉了？
- [ ] 对白是否像真人说话，而不是主题句或谜语？
- [ ] **有没有谜语人**：该直说的背景/因果/状态是否让人猜？专名有没有人话托住？
- [ ] 删掉总结句后，场面本身能不能站住？
- [ ] 抽象感觉（闷、沉、有分量）有没有换成可听可见的动作/象声？
- [ ] 声音是「咚咚」还是「闷，一下接一下」？
- [ ] 有没有第一次出现就没讲清的设定黑话？背景是否先让人站稳？
- [ ] 人物关系、续名/战死因果、该落地的情感有没有写明？

## 专名统一（写特定书时）

- 写/改 **`小说/九州英灵，随我收复河山/**`**：必须叠用项目 skill **`九州英灵-设定词`**（宿主三态、英灵/应召、灰膜、魂障/魂路闭关、名核/名沉等全表；禁用替身/JOJO/行尸等）。落盘前按该 skill「落盘自检」勾一遍。
- 其它书若有专名表，以该书 skill / 大纲词表为准；**同一段不换着花名叫同一事物**。

## 工作方式

- **默认强制**：凡写/改 `小说/**`，落盘前必须按上方「改稿自检」整表跑一遍；不合格先改再交。用户无需每次口头说「跑一遍 skill」。
- 项目规则：`.cursor/rules/living-prose-novel.mdc`（globs: `小说/**`）与本 skill 配套；冲突以本 skill 全文为准。
- 用户点出某段 → 只改该段及同类句。
- 用户说「全文照这个改」→ 通读全文，按上表扫干净再落盘。
- 改完不复述任务、不报「已自检」流水账；需要时用一两句点出改了哪类问题。
- **剧情/设定/人物弧/开头结局**：不归本 skill。用户要通读找逻辑漏洞时，改用 **`novel-logic-audit`**（全书→卷→章三遍，只查不改）。
