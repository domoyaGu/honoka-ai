## 逻辑链（为什么爽且说得通）

1. **灾从哪来**：境外**双轨**（复活爱人 + 魂附战士）同机拧车 → 母体+魂怪（见母体由来）。 
1b. **母体为何要活人**：**圈养**（爱人轨残留：要活锚）；宿主/黑史魂（军方轨残留）。 
2. **为何像「整个国外」在打华国**：沦陷带连片，黑史魂+魂潮受母体调度。 
3. **外国历史人物为何站对面**：军方轨拉起的强魂样本，翻车后被母体染成**黑史魂**。 
4. **为何只剩江南**：国外先炸；**吞噬要时间**；北邻境先轮到；**魂路闭关**；**北陷后**英灵才成（见专节）。 
4b. **北方丢了为何还能召**：应召吃**名沉**（名录南迁），不吃实控；上古～近代均可召；故地只加成。 
4c. **沦陷≠死城**：**牧场化**；踏平=圈入牧场；打仗=付学费；吞噬分期（见圈养专节）。 
4d. **华国为何不染 / 唯华国有英灵**：境外走脏附体翻车或没研出来；**只有华国**名录共鸣·应召做成。 
5. **华国如何翻盘**：干净英灵 + 补憾收城 + 陆铭送人对位；后期拧潮借刀。 
6. **点名双爽**：报我方名将→全国定心；揭敌方黑史魂名→紧张后更期待对位胜。 
7. **陆铭为何后期能操纵魂怪**：感应本质是经周公碰魂层；感应熟了就能「推」——先推无主杂潮，再推高阶。黑史魂有名核，不当操纵玩具。 
8. **不断更**：一线对位胜+收城 → 捷报 → 下一线红灯；陆铭权能每卷一台阶。 
9. **永灭**：早期我方次席钉规则；敌方黑史魂可永灭作爽点；我方名将默认不送。 
10. **魂怪为何不核平**：要活名税+宿主壳；核平=饭碗砸了还搅己巢（见热武器专节）。

### 为何只剩江南（已定 · 用户钉）

**人话**：国外先出事 → **一块块吞噬要时间** → 北边先轮到先丢 → 华国**魂路闭关**拖住南灌 → 英灵赶在江南被啃穿前做出来。

| 因 | 说明 |
|----|------|
| **1. 源在外** | 实验意外**先在国外爆**；魂怪与母体境外起源。 |
| **2. 吞噬要时间** | 一城城圈牧场+铺巢征宿主；境外**强魂曾抵抗一段后仍全败**（见专节）。不是按钮全图变色。 |
| **3. 北方邻境** | 贴沦陷带，相对先轮到；闭关启动时北线已救不及。 |
| **4. 魂路闭关** | 北陷警报后立刻停航封港、魂障/名录网，拦飞机宿主与空漂。不是封建锁国。 |
| **5. 英灵只有华国做成** | 魂怪出现后各国都想搞；**境外没来得及 / 走错路**（双轨附体·永存翻成母体）。**唯华夏名录共鸣·应召**在北陷后研究成功并列装。 |
| **6. 江防站住** | 吞噬耗时 + 闭关顶窗口 + 华国英灵列装；潮有配额。 |

**禁止**：写成华国一开始就有英灵却仍莫名丢光北方；禁止写成魂怪「碰水就化所以过不了江」。 
**正文口吻**：「北丢的时候名录署还在纸上画画；真召出来，江边上已经拉上闭关网了。」

### 魂路闭关与过江/过海（已定 · 替掉旧「渡江不对称」）

**你的质疑成立**：魂可附身坐飞机，魂体也能漂——**单靠长江水面挡不住**。旧「水难渡」作废。

**主钉：华国北陷后第一时间「魂路闭关」。**

| 层 | 做什么 | 挡住什么 |
|----|--------|----------|
| **停航封港** | 民航军航停、港口封、不明飞行先打后问 | 宿主登机空降江南 |
| **魂障/名录网** | 沿江沿海+腹地节点；与后来英灵江防叠用 | 无锚/远漂魂体易散、易暴露；大潮整建制难灌入 |
| **识别打击** | 黑气航班、黑气船、渗透宿主 | 鉴黑+防空+英灵斩芽 |
| **仍会发生** | 小股偷渡、空飘残渣、走私宿主 | 岭南清渗透戏；**不是铁板一块** |

**魂体自己漂？** 
能漂，但是**无锚裸魂=很弱**（见专节）；再加闭关网搅，到江南多半是可清渗漏，不是指挥链搬家。

**附身坐飞机？** 
灾初北线来不及拦；闭关后江南侧**禁航+打黑气机**。偶有漏网=渗透事件，不是常态空降军团。

**和「吞噬要时间 / 巢网扎根」的关系** 
母体在境外也是**分期吞**：占城→圈牧场→抽稳→再开下一城。华国赢的是这段工期里拉闭关、做出英灵。 
渗进江南的零星宿主，要在闭关网里**铺巢井、驻黑史魂**仍极难——英灵专砍冒头芽。闭关拦运力；吞噬工期+斩芽拦扎根。

**华国北伐为何能过江？** 
闭关闸门在自己手里：开战则**定向开廊**（舟桥/临时航线），英灵清滩头，有伤亡。敌方没有「华国发通行证」。不对称来自**谁控封锁网**，不是谁怕水。

**「闭关锁国」会不会有问题？**

| 风险 | 怎么圆 |
|------|--------|
| 听起来像封建锁国、挡不住魂 | 正文官称**魂路闭关令**；街口可骂「又闭关了」。本质是魂障+停航，不是只靠海关表格 |
| 北人为何没被闭关救下 | **救不及**：邻境先灌，网是往江南/长江一线拉的 |
| 闭关是否太满、戏没了 | 钉死**有渗漏**；岭南鉴黑、空飘残潮常有 |
| 与英灵晚成是否打架 | 不打架：闭关是**灾后第一反应**（先活下来）；英灵是**稍后研究出来**（才能反推） |
| 协防国/外贸 | 一句带过：特许人道/军援廊，受检；不展开 |

禁止：写成魂怪不会坐飞机/不会漂；禁止写成闭关后零渗透；禁止用「长江水克魂」当主因。

### 江防僵持 → 为何现在才北伐（已定）

时间感（约数，正文不报年表）：翻车→北陷→英灵列装后，**先守江约一代人**。

| 阶段 | 干什么 |
|------|--------|
| 守江期 | 扩编英灵、稳名录、顶渗透；试探渡江吃过亏，收回来 |
| 近十年 | 灵魂感知编入编制；能标巢距/辨黑史魂脏名压 |
| **当下** | **陆铭**入编=第一例稳定巅峰感知；五线北伐总攻窗口打开 |

所以不是「有岳飞却躺了四十年」，是**守得住 ≠ 推得动**；缺感应官式感应时北推浪费名将。陆铭出现=开战铃。

#### 8. 战后恢复组（收城之后 · 已定）

> **出场时机**：前期少写；**至少拿下一块可守的新复区之后**再加权重。

**恢复节奏（有新复区之后才拉满；顺序别乱）** 
1. 医 → 2. 水 → 3. 路 → 4. 粮田 → 5. 工

**和战斗组关系** 
- 恢复组进场时留警戒；陆铭不泡恢复长戏，听完「通了」就去下一条红线。

- **禁止**五线恢复同时开长戏；同一时段最多跟**一处**新复区的基建镜头。

## 敌方：沦陷全明星与厉害魂怪（已定）

### 黑史魂是什么（人话）

军方轨本就强拉、固化历史强魂样本准备附战士。翻车后母体污染名核——战法外形还在，自我拧成「征服/**把江南圈进牧场**」（文宣可喊踏平，**实指吞并驻守，不是杀光**），**周身黑气**，可指挥魂壳潮与宿主。爱人轨的「永生」渣渗进调度口吻，但不洗白。

| | 华夏英灵（我方） | 黑史魂（敌方） |
|--|------------------|----------------|
| 外观 | 史威外显，史威干净 | 有史威轮廓，**缠黑气** |
| 操控 | 召唤者清醒 | 母体/巢网拧着；**无对等活人召唤者**；可骑宿主 |
| 永灭 | 我方极稀；人重伤不醒 | 可打掉当爽点；敌方也无法再召；**无「召唤者不醒」对称** |

识别：陆铭近距能感应出「名沉被污染过」；肉眼看黑气；广播会做敌方点名。

### 写法禁区（敌方）

1. 禁止把拿破仑等写成「其实想帮忙」的友军洗白。

| **军方轨** | 境外军方 | **强大灵魂附身战士**（含历史强魂样本）当兵器 | **宿主夺控** + **黑史魂**军团 + 征服/圈牧场 |

**为何想法不同、目的却同** 
都要「魂可调用、可落地」。资方要的是**一个人回来**；军方要的是**一批人变强**。共用唤魂/固魂/附体底层，协议目标写成两条，联调时抢同一条魂路 → 正反馈炸炉。

**母体是什么** 
不是单纯「大怪」，是双轨揉烂后的**灾核**：对外一张爱人脸（温柔永生），对内跑军方调度（潮、宿主、黑史魂、牧场）。陆铭后期能感应出里面两种声音拧着——可作卷三～四感知戏，不讲课。

**面具（钉）** 
**薇拉·恩格尔** = 资方要复活的**爱人**之名/残影脸（不是科学家路人甲）。卷三起现身；碎面具≠母体死（母体核仍在）。资方本人：事故中被卷进炉，可当一句黑史，不必出场。

**和华国英灵的对照** 
境外：强拉、附体、复活 → 脏。华国：史籍名录共鸣、英灵并肩 → 干净。技术亲戚，伦理与协议不同，所以不染。

**写法** 
- 前期军史一句：「境外双轨实验，资方要活人，军方要枪，拧到一块了。」 
- 禁止长篇实验室回忆录；禁止把母体洗成「其实只想爱人」。爱人渣是诱饵皮，主体仍是灾与牧场。 
- 禁止现实国族说教；灾因落在**双轨拧车**。

### 各方
| 阵营 | 路线 | 结果 |
|------|------|------|
| **境外沦陷世界** | 双轨意外 → 母体+黑史魂+牧场 | 压境华国 |
| **华国** | 灾后名录共鸣 → 干净英灵（北陷后才成） | 守江南，北伐 |
| **周边协防国** | 联防（常规力量） | **无自研英灵**；可接华国外派编制（稀） |

### 华国为何不染 / 名录为何还在（已定）

| 点 | 钉法 |
|----|------|
| **不染** | 母体污的是**强拉/附体**产物（军方轨样本）。华国**名录共鸣·应召**另一路，污不动或极慢。 |
| **名录砸不烂** | 名录署在江南腹地；敌主攻巢线与渗透；鉴黑可写，不靠忘了写。 |

### 只有华国做出英灵应召（已定 · 用户钉）

**人话**：干净「英灵并肩、不夺舍」这套，**全世界最后只有华夏国做成了**。

| 谁 | 结果 |
|----|------|
| **境外（实验国等）** | 走双轨：复活爱人 + **强魂附战士** → 拧车变母体；等于把「附身兵器」做成了灾。来不及另开干净英灵路。 |
| **其它未炸先沦陷国** | 抗的时候还在摸索；**没研究出来**就被牧场化。 |
| **华国** | 灾后另开**史籍名录共鸣**；北陷后成功 → 身旁应召列装。 |

**协防国** 
可有常规军、情报、后勤露脸；**禁止**自研自召一堆外国干净英灵集邮。若露英灵，只能是**华国编制外派**（华国召唤者+华国名核），且稀。名录协议：外国不得接绑华国名核。

**和「无锚裸魂弱」** 
境外强魂多是裸抗或脏附身；华国独一份稳定活人锚应召编制 → 才能北伐。

正文口吻：「外面想做的时候，人已经没了；做成的，只有咱们。」
### 两种上身 + 第三种高战
- **魂怪附身**：夺控活人；周身黑气。 
- **华夏英灵**：身旁应召体；干净；随时可召；英灵可拒收。 
- **黑史魂**：外国历史强魂被污染；黑气史威；可永灭。 
- **无销史**。

### 无锚裸魂很弱（已定 · 可作设定）

**人话**：魂要借「活人锚」才打得动。不是「必须夺舍」，是**不能裸飘当战力**。

| 形态 | 有没有活人锚 | 战力 |
|------|--------------|------|
| **无锚裸魂**（空漂、残响、没召唤者） | 无 | **很弱**：稀、散、瞎；渗漏炮灰级 |
| **魂怪附身** | 有（夺控的肉体） | 强；半控/空壳见词表 |
| **华夏英灵（应召体）** | 有（召唤者活人；**并肩不夺舍**） | 强；永灭靠它 |
| **黑史魂** | 巢网/母体当脏锚；**可再骑宿主**加硬 | 强；掉锚或锚烂会掉档 |

**为什么这设定好用** 
- 解释魂怪要宿主、空漂过不了闭关网。 
- 解释境外「强魂裸抗」最终仍败：缺稳定活人锚/应召编制。 
- **不废华国全明星**：应召体=锚在召唤者身上，不是弱。

**禁止** 
写成「英灵不附身就弱」（等于废身旁应召）；写成华夏英灵必须夺舍友军才能打。

### 附身后：原灵魂怎么办？（已定 · 用户钉）

**人话**：魂怪骑上来，本人灵魂被按住——**半控**；人没了只剩身子推着走——**空壳**。  
**正文主词只准三档**：宿主（总称）/ 半控 / 空壳。词表见 skill `九州英灵-设定词`。

| 主词 | 原灵魂 | 身子 | 战场怎么处理 |
|------|--------|------|--------------|
| **宿主** | — | 总称：周身黑气、被夺控 | 人打宿主；先分半控还是空壳 |
| **半控** | 被按住，还在 | 会动会开枪，眼神空 | **优先驱离黑气救人** |
| **空壳** | 已无 | 黑气推着走 | 可击毙；不当种畜 |
| **牧场民** | 还是自己 | 未附身，怕、干活、被抽税 | 不是宿主 |

**陆铭经周公能感应什么**  
半控：身子里还有人在挣。空壳：没有人，只有黑气。用来决定救还是毙。不是靠自己耳朵尖，是应召周公后碰魂层。

**禁止**：同段把宿主叫成行尸又叫机器又叫壳；附身=原魂瞬间蒸发；全城人人宿主（违反牧场化）。  
**废词（正文）**：行尸、机器——不作编制名；描写可用「发僵」「没人了」。

### 境外强魂也曾抵抗（已定 · 用户钉）

翻车后境外不是秒沦陷：当地**强大的灵魂**（活人强意志、早期觉醒者、未染史魂残响等）**硬抗过一段**，拖慢吞噬工期——**最终仍全军覆没**，才变成如今连片牧场+黑史魂。

| 点 | 钉法 |
|----|------|
| **用途** | 解释「吞噬要时间」；正文军史/陆铭听残响一句即可 |
| **结局** | 都败了；本传不写境外抵抗长篇，不洗白黑史魂「其实是抗敌英雄」 |
| **和黑史魂区分** | 抵抗的是**当地还干净时的人/魂**；黑史魂=军方轨样本被母体油污后的征服兵器，不是那些抵抗者的续集 |
| **为何仍败** | 裸抗/脏附身；**没做出干净英灵技术** |
| **华国对照** | 境外抗输了；**唯华国**在闭关窗口里做成应召英灵，才没步后尘 |

正文口吻：「外面也有人扛过，扛输了。」

### 母体/魂怪为什么要活人？（已定）

**人话一钉**：**魂怪要圈养人类。** 不是爱，是牧场。

| 吃什么 | 说明 |
|--------|------|
| **活名流（主食）** | **爱人轨**残留：死的召不稳，改抽还在喘气、还在被叫的名当锚；细水长流。死人冷残渣养不住巢。 |
| **宿主壳（手脚）** | **军方轨**残留：强魂附战士协议的翻版；占城、开枪、守井。 |
| **城=牧场** | 两轨合流后的稳态：人还在户才抽得稳。核平=宰光牲口烧牧场。 |

**死人**：脏油，搅巢。 
**对照**：华国吃史籍名沉；母体吃活名流（圈养）。 
正文：「它养人，跟养牲口一个理。」根源一句可接：「有人想召回一个死人，召翻了，就改抽所有活人。」
### 圈养引申钉死（第五轮已补）

| 项 | 定法 |
|----|------|
| **沦陷观感** | **牧场化**：街上有人、有怕、有劳作被抽；不是尸海。宿主=征走的牲口。 |
| **「踏平」语义** | =吞并**圈入牧场**、驻守抽税；≠屠城灭绝。黑史魂过火屠城 → 巢网/母体勒回（可写一次）。 |
| **打仗烧人** | =**付学费**：配额内消耗换掉华国英灵威胁；腹地牧场保种畜；潮**不是无限兵海**。 |
| **吞噬工期** | 境外/失土都是**分期圈养**，不能瞬吞全球；给华国闭关与研英灵的窗口。 |
| **宿主与税** | **半控**：原魂被按住，还喘气 → 可薄抽。**空壳**：原魂已无 → 军费炮弹。牧场民未附身才是主粮。 |
| **为何还啃江南** | ①江南有英灵，能永灭巢核=**存在威胁**；②人密名热=未入网**肥牧场**。去威胁+抢肥田。 |
| **为何不纯围困** | 英灵会北伐切牧场；龟缩=地一块块丢。必须前出压制。 |
| **黑史魂永灭** | 投放体：断线、伤局部巢；**不秒母体**；卷四打母体核。 |
### 失土与应召（已定 · 堵「北方召不了」）

**结论：北方沦陷 ≠ 北方英灵召唤不了。**

丢的是城和人，不是史书里的名字。应召吃的是**名沉**（被记住的强度），名沉在史籍、名录署、南迁祠堂、族谱和血脉记忆里——随京畿/难民撤到江南，所以岳飞、李牧、韩信都能在江南或江防应召出英灵，再随北伐线北上。

| 锚 | 作用 | 失土之后 |
|----|------|----------|
| **名沉（主开关）** | 史书/名录里还有这位，就能列装 | 无销史；史还在 → **仍可召** |
| **血脉 / 执念** | 谁来当召唤者 | 北人南迁、军中后人在江南编制里 |
| **故地** | **加成，不是开关** | 距故地越远折扣越大；**沿海名将在东海线折扣小**（卷一能胜）；中原名将在江南折扣大，**打回巡区才全盛** |

禁止：「中原丢了所以岳飞召不出」；禁止「必须站在开封才能第一次召」。 
允许：江南/江防先点名定心召出 → 打回汴京巡区史威暴涨、补憾落地。 
正文第一次用名录署一口人话科普：「地可以丢，名录在我们这儿；打回家乡，他们才是全盛。」

### 时代范围（已定 · 含近代）

**凡进华国史籍/名录、名沉够厚的，上古到近代都能应召**——不限汉唐宋明。 
近代（晚清～抗战前后等）同样走身旁应召、一名核一尊、可拒收、永灭规则。

| 层 | 例（可增减） | 用法 |
|----|--------------|------|
| 上古/秦汉 | 韩信、李牧 | 粮道、边关 |
| 三国～宋 | 诸葛亮、岳飞、戚继光、郑成功 | 中原/海防门面 |
| **近代（本传锁定）** | **邓世昌、左宗棠、杨靖宇、詹天佑、徐光启、张謇** | 海战/西陲/苦抗 + **路/农/实业恢复** |
| **岛链/台湾门面** | **郑成功**（明末清初，名沉锁东海） | 台海岛链升旗、开港、航线重开 |
| **恢复向** | 华佗、孙思邈、张仲景、李冰 | 医与水；战后跟灯图进场 |
| 再近 | 慎用 | 上限建议：抗战及以前；更近除非你点名加 |

**写法**
- 古今同场：岳飞开路，近代守侧翼/巷战/护民。 
- 补憾具体：邓世昌对岛国海战、郑成功台海岛链、左宗棠西陲、杨靖宇东北苦抗、戚/俞御倭。 
- 禁止现代武器展览压过英灵对砍手感；近代仍是魂侧英灵对砍。 

### 应召方式（已定 · 随时召 + 英灵有主见）

**形态**：英灵以**应召体**显在召唤者身旁并肩作战——非夺舍，非法阵唱名；意念即出即收。  
**加一条**：英灵**有自己的想法**，不是完全听话的遥控器。  
**禁用词（防撞脸）**：正文与设定对外叙述**禁止**写「替身」「Stand」「JOJO」等外来梗名；只说应召、应召体、名录共鸣、英灵。

| 项 | 定法 |
|----|------|
| 怎么出 | 匹配成功后意念一动即放；人侧默认**随时可召** |
| 怎么收 | 人侧默认想收就收；英灵执念未了/不服时**可以拒收、赖着不回** |
| 要不要仪式 | **不要**。无阵无咒无一日一次。点名广播=文宣/编制，不是召唤条件 |
| 召唤者状态 | 日常清醒可指挥；英灵吃伤反馈到人 |
| 英灵意志 | 会说话、会顶嘴、会自己冲；体力还够时可抗命**拒收** |
| 人累瘫 | **英灵强制收回**（人侧油尽，英灵撑不住场）。拒收不能突破这条——瘫了就回 |
| 英灵永灭 | 名核熄、无法再召；绑定的召唤者**直接重伤不醒**（长昏迷/危殆，不当场必死，除非再补刀） |
| 谁说了算 | 日常人指挥；冲突时名将可拒收；人一瘫，系统强制收，英灵再硬也回 |
| 谁能匹配 | 觉醒者；血脉/执念/故地共鸣初次绑定 |
| 一名核一尊 | **同时全军仅一尊该英灵应召体**（编制独占，禁止双岳飞） |
| 换绑 | 原召唤者**主动解除**、**普通战死**（名核未熄）或**永灭后该名作废**——前两种可由名录署重测换人接绑；永灭则永别 |
| 数量 | 常人顶多双魂；名将稀缺 |
| 双魂永灭 | **任一尊永灭 → 人重伤不醒，另一尊强制散** |
| 应召距离 | **近距同战场**（目视/同阵地级）；拉太远不稳，逼召唤者跟人走——从机制上否决基地遥控 |
| 陆铭 | **周公**应召开感应、不当刀；**编制锁定单魂**；护卫编组，不单挑宿主 |

**拒收怎么写**
- 补憾高潮：人还站着、下令后撤，英灵偏要插完旗再走。 
- 性格戏：韩信不服调、岳飞不退中原。 
- **禁止**整卷全拒收；多数配合，拒收是爆点。 
- **禁止**「人已经瘫了英灵还在外面硬打」——瘫=强制收。 
- 永灭场面：黑气散尽，召唤者一口血直接不醒。

**禁止**：祭台满月；住牌/殿；黑气与应召体混词；零个性遥控器。

**和「点名定心」**：广播=谁到岗带哪张王牌，不是念咒。

### 战场分工（已定 · 同场不同打）

**否决**：人缩在基地遥控英灵。 
**定法**：人与英灵**前线同场**，对象分层。

| 谁 | 主要打谁 | 说明 |
|----|----------|------|
| **英灵（应召体）** | **魂怪、黑史魂、巢核/分芽** | 魂侧对砍；**永灭只能英灵做** |
| **觉醒者本人** | **黑气宿主** | 人对人；优先**驱离黑气救人**，宿主已空壳才得击毙 |
| **常规军** | 魂壳残渣、外围、后勤火力 | 不穿名核 |
| **陆铭** | 感应、拧怪、报坐标 | 护卫陪同；观察/指挥位 |

**黑史魂怎么打（钉 C）** 
- 默认：独立魂侧单位 → **英灵主打**。 
- 若骑在大将宿主上：人先剥宿主，英灵打黑史魂本体。 
- 永灭黑史魂：**无**敌方「召唤者不醒」对称。

**陆铭拧怪边界（新钉）** 
- 默认可拧：无主杂潮、侧翼壳、未与我方英灵硬咬的怪。 
- **禁止**随便拧「正与我方名将对咬」的目标抢斩（除非名将危急救场、陆铭只拉开杂咬）。 
- 卷3误拧 = 感岔代价，已设计。

**同场怎么写** 
左：人扭宿主；右：英灵对魂侧。英灵可挡刀护主。

**禁止** 
后方喝茶遥控；人徒手永灭高阶；英灵砍普通平民（打黑气与魂，救人优先）。

### 热武器与核弹（已定 · 不对称）

**人话**：结果都是战场上不扔战略核——**原因不能写成「两边都觉得不划算」**，那是作者对开。

| 谁 | 性质 | 一句话 |
|----|------|--------|
| **魂怪** | **不想用**（动机） | 主食是**活名流**；核平=饿死自己还搅巢 |
| **华国** | **用不了 / 用过一次更糟**（能力+战史） | 库大半在沦陷区；翻车初试过战术级，雾更厚 |

#### 常规热武（对称，没问题）
双方都用枪炮坦克打肉与壳。永灭名核仍靠英灵。常规军要养。

#### 魂怪不核平江南 = 动机（主问）
根子在「要活人」专节：主食是**活名流**，不是尸体。

| 原因 | 人话 |
|------|------|
| **活名税** | 人死光 → 没得抽 → 巢网饿/散；焦土=砸饭碗 |
| **宿主壳** | 占城打仗要肉身；核平无壳 |
| **脏死魂** | 战略核一次性灌脏油，搅己方巢网（不是盛宴） |
| **按钮** | 完整发射链靠活人授权；宿主狂化端不住 |
| **占城执念** | 黑史魂要征服驻守，不要大坑 |
| **禁核** | 有井试过战略级被母体反噬；之后巢网层默认禁 |

敌方主手段：潮、巢、宿主、黑史魂。

#### 华国不核扫江北 = 不是「也不想」（堵对称味）

1. **库没了大半**：战略发射井/重库多在江北与边疆沦陷区，宿主或黑史魂坐着；江南手里剩的是短程/战术级，不够「扫平江北」。 
2. **翻车初试过一次**：华国对某个冒头巢打过战术级——城平了，名核还在，死魂一搅**雾更红**，还差点反灌下游。这是教材，不是哲学。 
3. **剩下那点是自毁选项**：真摁，江南自己先吃黑雨/江防崩；参谋会上有人提，被老兵拿战史拍死。 
4. **永灭仍靠英灵**：核打不穿名核——这是补充，不是主因；主因是**没牌 / 试过更糟**。

正文可留一句牢骚：「不是咱们仁慈，是按钮不在南岸了。」有人喊扔核，用战史顶，不讲「双方共识」。

#### 收复北岸之后怎么圆？（必堵）

收复≠战略核复活。分层钉死，正文按战线推进随口带，不必单开讲座：

| 层 | 人话 |
|----|------|
| **1. 井在，弹废** | 发射井多被巢当根脚或炸塌；弹头魂污/锈死/被宿主拆散。进城能清巢，**清不出一套能射的战略链**。 |
| **2. 链断了** | 授权、密钥、测控人在翻车里死绝或成宿主；重建要年，北伐等不了年。 |
| **3. 物理仍废** | 即便搜出几枚还能响的——**打不穿名核**，大死亡还可能喂雾。翻车初那一炮的账还挂着。 |
| **4. 纪律** | 国策写死：收复区核设施**只封、只拆、只南运封存**，禁止发射。有参谋想拿回收弹砸母体巢，被战史+名将当场摁住（可作一卷小冲突，不是主线）。 |
| **5. 终局不靠它** | 打母体/黑史魂指挥链靠英灵+陆铭搅局；核不是隐藏通关键。 |

**时间线口吻**：江南阶段——「按钮不在南岸」；过江收城后——改口「城收回来了，火没了」或「火还脏着，碰谁谁倒霉」。

**禁止**：收复北岸后突然战略核雨清图；用「终于可以扔了」当爽点。 
**可写**：某线收下一座库城，工兵封井、恢复组标红「勿启」；有人密议动弹被否。

**禁止（总）**：写成「敌我约好不核」；敌方核平开局；我方核武一键清图；热武器废铁。 
**可写（总）**：沦陷区偶发失控小爆；华国战术级黑史一句带过。

### 国策与为何没早亡（钉 F）

守江南 + 五线北推；不轻言全球远征。 
**为何没早亡**：见「为何只剩江南」（含**吞噬要时间**）+「魂路闭关」+「僵持→北伐」。
 
**灭母后境外还在**：本传只收河山；境外牧场与残巢不义务全球清算（卷四收束钉死）。 
**收复区住人**：清宿主→迁民回灌+恢复组短笔；抽的是魂压不是血，人虚可医。---

## 爽点发动机

### A. 点名定心（我方 · 短剧「朕有」）
报华夏名将 → 街口松气 → 下场开干。同卷≥2次。 
可连报：「岳飞中原、戚继光东海、郑成功台海」——**阵容展示**。

### B. 敌方点名（对称爽）
统帅部通报「某某黑史魂出现在某线」→ 全国一紧 → 我方点名对位 → 更定心。 
例：「中原线拿破仑级」→「岳飞赴汴南」→街口有人骂「来得好」。

### A2. 富裕之仗 / 梦幻联动 / 论功（短剧对齐）
- **富裕之仗**：粮、轨、药先到位，名将明说「这回能打满」——对标孔明「没打过这么富裕的仗」。 
- **梦幻联动**：跨时代名核同场（每卷至少一次合影级镜头）；医线华佗+孙思邈+张仲景**会诊**一次。 
- **论功短切**：大胜后封赏/晋名录/祭名墙，半章内收束，不开朝堂。

### A3. 英灵相见礼仪 + 人物简介（必写 · 已纠正）

**英灵彼此能看见、能说话**（英灵同场即成立）。 
**不是人人见面都哥俩好寒暄。** 按辈分/名位/时代压，像军中见礼：

| 关系 | 怎么说 | 例 |
|------|--------|-----|
| **后辈 / 后世将见先辈名将** | **仰慕、崇拜、称公侯/将军、少叙己功** | 后世将军见关羽、见岳飞：敬语+一句「晚辈读过××」 |
| **偏将 / 下级见主帅型名核** | **敬礼、听令、称职衔** | 随从灵见岳飞、姜维见诸葛亮：先礼后言 |
| **同辈 / 同侪 / 旧搭档** | **才互相寒暄、打趣、叫旧称** | 卫青↔霍去病；戚继光↔俞大猷；师徒间熟了也可松半句 |
| **素未谋面但久闻** | **单方面久仰**，不是对等寒暄 | 邓世昌见郑成功：先敬后谈海 |
| **对家 / 隔阂** | 可僵、可点头、可不热络 | 点到为止，别强迫握手言欢 |

**禁止**
- 禁止近代小将跟上古名将对等勾肩搭背。 
- 禁止所有英灵见面都「嘿兄弟」。 
- 禁止为寒暄停战开会；一两句见礼就开打/散场。

**人物简介（防读者懵）** 
每个**名核门面**第一次正式出场，出来前或出来后不久，嵌进「这人历史上干过什么、为何厉害/有啥憾」——广播一句、军人嘴、街口反应、本尊半句均可。 
随从级可省；岳/关（若用）/戚/郑/韩/诸葛/霍/卫/邓/杨/华佗/李冰等**不可省**。 
简介挂钩未竟更好；禁止说明书停战。

**开写自检**：新名核 → 简介有无？同场见面 → 礼仪对不对档（敬/礼/同辈寒暄）？

**正文写作硬规则（已定 · 用户钉）**

1. **禁废话，不禁篇幅**：对位、定心、伤后、巩固、人物反应——写够（单章宜充实，勿千字提纲腔）；禁止设定小课、无压力清巢流水账、长篇商税工业文、空转开会。

4. **每章一场戏**：一个地点、一组核心人；禁止一章五线开会。  
5. **同时活跃**：我方核心出场≤4；敌方高战同时≤3。  
6. **中后期（有稳固新复区后）**：边基建边打仗；恢复服务前线，不另开纯基建卷。  
7. **正文禁写对标/借鉴梗名**（含变体口吻）：全明星、JOJO、替身、Stand、领路人、独自升级，以及「像某作品那样」式点破。世界内只用本传专名（英灵、感应官、点名定心等）。

## 主角：华夏第一灵魂感知（已定）

**陆铭**（定名）：江南滨江人，战力评极低；应召**周公**开**感应**，全国顶尖感应官；全明星的雷达 → 后期兼撬棍。  
与废稿「陆铭」无关：无拓影牌。  
**手感对标**：末日序列公路求生里的**领路人**——凝神扫危险/真假岔路、指安全向；不当输出。感知通道是**周公**，不是自带超人听力，也不是靠闻。

### 家人（已定 · 用户钉）

| 项 | 定法 |
|----|------|
| **姐姐** | **陆晚**（可改名）。兄妹**相依为命**；滨江开药店/过日子，陆铭上前线她守后方。 |

### 陆铭为何是「第一感知 / 感应官」（已定）

| 点 | 钉法 |
|----|------|
| **通道** | **应召周公 → 感应魂层**。周公不当输出；陆铭本人无自带超人听/闻。 |

军方二阶起又用又防：像能拧敌潮，防他「太像那边」——编制摩擦可写，**不真投敌**。

### 权能三阶（已定）

| 阶 | 大约卷 | 能做什么 | 不能做什么 |
|----|--------|----------|------------|
| **一阶 · 只感应** | 卷1～卷2中 | 经周公扫潮向、巢核、名沉共鸣、黑史魂脏名压、名将负荷将崩；指真假岔 | 拧不动任何魂怪；不是预知钟点；周公不输出 |
| **二阶 · 操纵低级** | 卷2末觉醒，卷3稳定 | **驱散/改道/互咬**：杂潮、灰膜魂壳、无主低阶怪；短距、耗神 | 动不了巢核/分芽/母体；动不了黑史魂；动不了我方英灵 |
| **三阶 · 操纵高级** | 卷4 | 短暂**拖住、调转、撕开**分芽级/高阶魂怪触手；可搅母体近端投影 | **不夺控黑史魂名核**；不永久收编高怪当宠物；不独斩母体；斩杀给名将 |

**人话**：先只会开周公扫路，再学会拨低档旋钮，最后能猛扳高档——旋钮炸手，歌还得名将唱完。

### 操纵规则（防开挂）

1. **对象**：只限魂怪（及母体的怪质部分）。黑史魂=污染史魂，有名核，陆铭可干扰黑气/节奏，**不能当傀儡驾驶**。 
2. **三限同样套在操纵上**：感岔→拧错目标；母体干扰→操纵失灵或反噬；距离衰减→人必须在场，京畿遥控拧潮=违规。 
3. **代价**：耳鸣、鼻出血、短暂失聪、反噬被黑气刮一层；卷3误拧要付战场伤亡。 
4. **禁区**：不操纵我方英灵；不靠操纵抢收城镜头、抢对位斩将、独吞灭母。 
5. **观感**：二阶起军方又倚重又防他「太像魂怪那边的人」——可写编制摩擦，不当主线虐。
