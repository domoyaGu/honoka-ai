## 一句话

公元 3000 年，多国「回声计划」共时撕裂，魂怪盘成**巢穴**。血脉召唤者震近本尊；本尊永灭则销史，华国靠续名续传。华国 E 级**陆铭**养病姐**陆若若**，开局震出的是周朝**无名工匠**——此人受命铸**试名牌**，本意就是在名将散未散时**拓别人的影**，不靠血脉独占本尊。第2章工匠燃己把牌「烧活」后永灭，牌归陆铭。其后 S 将死现场，牌按铸造法自动拓影入**英灵殿**；陆铭召的一律是影，当前战力跟他自己，上限摸本尊档。对外仍像耗材，对内座满职能影，对母体。母体是凯为**薇拉·恩格尔**之孽；姐线问要不要永生。---

## 「影」（已定 · 全书核心）

陆铭试名牌召出的，**从来不是英灵本尊，只是影**。

| 概念 | 含义 |
|------|------|
| **本尊 / 名核** | 钉在史册与集体记忆上的那一截；血脉强者震出的接近本尊；可被魂怪**永灭**→销史 |
| **影** | 名的影子、逃散名凝成的席；可与世上他人的同名召唤**同时存在** |
| **英灵殿** | 牌内冷殿；影落座、可对话试召；无抽卡界面 |

**强度两条杠（必须写清）：**
1. **当前战力** = 只跟陆铭此刻的负荷、抗性、名录实际能力走。他是E手感时，岳飞之影上场也像E随从。  
2. **实力上限** = 该影对应本尊的历史档（岳飞档封顶可摸S）；人练到了，影才能摸到上限，**不会无故超过本尊档**。  

读者一句话：**殿里坐的是影；上场多强看陆铭练到哪；再强也到不了「比本尊更强」。**

他人仍按血脉/名录震近本尊的英灵；陆铭外挂是「多影入殿 + 自动收逃名 + 影随他长」。不偷唯一本尊，故同名可重复。

## 收影主循环（已定）

### 编队规矩
中高危：**S带队**，E打杂（清小怪、搬骸、断末梢）。

### 收影：牌按铸造法自动拓（前两席靠S将死）
条件与工序见下节「试名牌如何拓影」。持有者可完全不知情。

**第1席**：拓了不懂。  
**第2席**（建议岳飞）：再拓一次 → 醒悟召的是**影**，名号吓人但上场弱得像E → 开始练自己。
### 英灵殿
冷殿、席位、影可应答；先能进殿见面，再能震到外头。

### 压力两边一起涨
| 阶段 | 陆铭与影 | 对面 |
|------|----------|------|
| 前两席 | 被动收影；挡刀濒死；影几乎震不出/仅E手感 | 弱→强分芽 |
| 醒悟后 | 练自身；短震影打杂 | 直属变难 |
| 露锋～再评测 | 影能打一场；引起招募复核 | — |
| 卷2后 | 少靠S死；重伤收影/特许；影逼近上限 | 准母体→母体 |

### 后续（前两席之后）
禁止场场吸死人。主循环：**练自身拉高影的当前强度 → 露锋 → 招募再评测 → 编制内用别的因果收影**（S重伤挡称、特许等）。

### 岳飞场
外围打杂 → 沈承岳将死、岳飞本尊将永灭 → 牌收**岳飞之影** → 销史/续名走沈档 → 陆铭醒悟后从E手感的影练起，上限指向岳飞档。
### 历史核对（岳飞收复的是哪）
- **不叫「金地」。**「金」是政权名：**金朝**（女真）。  
- 岳飞北伐要收复的是被金占领的**中原故土**（以汴京一带为核心的华北/中原沦陷区），不是一块官名叫「金地」的行政区。  
- 名句「直捣黄龙」：黄龙府为金早期腹地象征，指打进金的老巢。  
- **本书地理（已定）**：被高危巢长期占住的一片稳区边缘/巡区，名录署与民间都叫它**「中原失土」**（或公文「汴京故土巡区」）；收复战宣传口吻对齐岳家军「还我河山」。写作用「中原失土」，勿写成「金地」。

## 名词说明

### 「巢穴 / 清巢」
魂怪盘踞、把地方啃歪的那一团叫**巢**（弃厂、涵洞、旧轨、城郊废区；高阶也可暂时藏居民楼）。名录署标 E～S，觉醒者带英灵**清巢**结赏。现实地理，不是进本。低危巢可**炸档**——第2章。  
**为何成巢**：见下「人聚城 · 怪聚巢」。

### 「啃名」
啃掉「被人记住的名字与事迹」→ 人魂残、英灵残。**校对**可补。  
与「永灭销史」是一条绳上的两结：啃名是蚕食，永灭是整段历史被抽走。

### 「英灵 / 本尊 / 影」（开局少讲；需要时用场面带一句）
- 死后约 30 日魂散；被记住的成**名沉**，觉醒者可震取。  
- 常人匹配多靠**血脉 / 故人之裔**；震出的接近**本尊**。  
- 陆铭牌震出的是**影**：可同名重复；**当前强度跟主人，上限=本尊档**。  
- 热武器难永灭魂怪；须英灵魂侧打击才结清巢赏。  
- E 常见有名随从；S 稀缺，常人顶多**双魂**。  
- **本尊/名核**被魂怪永灭 → 销史；续名补史。影可留在英灵殿，会淡。  
- 陆铭开局：无名工匠（发明者；烧活牌后永灭）；其后入殿的皆为**拓影**。  
- 「影 / 拓影法」完整科普放到第2席醒悟时，不塞第3章。

### 「随从级」vs「无名」
他人 E：有名随从。陆铭开局：无名工匠（自隐其名的铸范人）。
### 「敲门砖」
**专诸**（奇袭练手；默认不占十二席点名）。

## 魂怪（样貌 · 与人区别 · 出没规则 · 已定）

> **已钉**：全书敌对单位 = **魂怪**。不写丧尸，不用丧尸比喻带读者，不借尸潮桥段硬套。

### 借鬼灭什么 / 不借什么
| 借 | 不借 |
|----|------|
| 能藏进人群、乍看像人 | **不怕阳光**（白天照样活动，只是更收敛） |
| 夜间/僻静处更敢动手 | 不是「被鬼变成鬼」的传染为主（本书以母体产怪、巢内滋生为主） |
| 低阶形残智浅，高阶像人、会说话 | 不抄十二鬼月番号体系（本书层级：杂怪→巢核→分芽→母体） |
| 普通人难永灭，要专门的刀/力 | 本书对应：**须英灵魂侧打击**；热武器难永灭 |
| — | **丧尸套路**：尸潮、咬人传染、只会扑咬的活死人 |

### 吃什么
优先噬**魂**与**名**（记忆里的称呼、事迹会糊、会丢）。肉体伤口可以有，但不是主食感——受害者常先「想不起自己叫什么/家人叫什么」，再虚弱。写低阶形残时也要让人看出「啃名」，禁止写成只会咬肉的尸群。

### 平衡结论（会不会太强、人类发现不了？）
**化人若只靠普通人眼力，偏强、社会清巢产业立不住。**  
已收：外观破绽降为「辅证」；**发现主渠道 = 觉醒者魂感 / 察名系 / 英灵在场**。普通人负责报警与自保口诀，不负责当探仪。

### 谁能发现（层级 · 已定）

| 谁 | 能发现什么 | 限度 |
|----|------------|------|
| **普通人** | 低阶化人差、已撕破的真形、影子培训口诀（亮灯对照）；发现「失踪/忘名」异常去报警 | **中高阶化人基本看走眼**；不能确认、不能永灭 |
| **所有觉醒者**（E 也算） | 靠近时有**魂压不适**：耳膜发紧、舌根发苦、想不起自己全名半拍——「这方向不对」 | 距离短；人多嘈杂易被盖过；**定不了是哪一张脸**（除非很近） |
| **识别者（B级起编入哨卡）** | 察名/感知向；**高阶化人也能识破**；哨卡标配，每卡至少一名B级 | 不是战力天花板；识得出不等于打得过——过卡拦截靠驻卡武力+英灵 |
| **察名系（听名员/标巢员等）** | 标巢、点人、海关；与识别者同向，岗位不同 | 高阶「借名」极深时要英灵/试名级手段复核 |
| **英灵已震出** | 大幅放大主人的感；英灵本身认魂侧——「那不是人」 | 未震出时加成弱；英灵越强辨得越清 |
| **试名牌 / 魂工残留仪器** | 「称」空名；名录署卡口、巢周探针用劣版 | 民用级不准；陆铭那块是例外（烫活的） |

**觉醒方向（简表，不必百科）：**  
主流是**震灵向**（请出英灵打架）。旁支里稳定吃香的是**察名向**（发现、标巢、海关/城检）。陆铭表面是震灵向 E；工匠在时偶尔教他「听」，牌活之后他的察名会歪打正着变强——仍不是名录署编制听名员。

### 与普通人的区别（样貌 · 辅证）

**化人时——像人，破绽给「确认」用，不给「全靠这个扫街」：**
1. 影子慢半拍 / 边缘发糊（培训教，慌的时候看不准）。  
2. 瞳孔或眼白淡灰膜纹。  
3. 呼真名空一拍（觉醒者/英灵在场更明显）。  
4. 体温偏凉、近巢铜腥潮冷。  
5. 低阶化人差：关节反折、笑容停太久。

**撕破真形：** 湿冷灰膜、细牙圈、根丝；体型可畸变。  
**分芽（第2章）：** 半人高、无五官、细牙、根丝、芽芯女声——母体触手。  
**绝对差：** 活人有完整「可被记住的名」压身；魂怪是空的或拼残名。察名系 / 牌 / 英灵吃这个差。

### 出现频率与活动规律
- 日常：隔三差五失踪/忘名；工单稳定，不是天天大战。  
- 夜间、雨天、僻静处更勤；白天可化人活动，**不怕阳光**。  
- 成巢：多只盘踞 + 根丝纹 → 听名员/探针标巢 → 派清扫队。  
- 单只游魂：常先被附近觉醒者「感到不对」再报警，不是靠路人一眼识破。  
- 滋生随母体收税与大灾余波起伏。

### 战力与永灭
- 热武器可打散，难永灭。  
- **须英灵魂侧**才永灭、才算清巢完成。  
- 越近母体/分芽，越会装人、越会啃名；察名系也更容易误判，要英灵复核。

## 人聚城 · 怪聚巢（为何成巢 · 已定）

回声撕裂之后，两边都在「抱团」，只是抱的东西不同。

| | 人类 | 魂怪 |
|--|------|------|
| 聚哪里 | **稳区城市**（电、药、名录署、人多互保） | **巢**（弃厂、涵洞、旧轨、城边废区；贴着城市，不进最亮的芯） |
| 聚什么 | 秩序、物资、体温、被记住的名字 | **魂与名**的浓度、根丝网络、母体「收税」好抽的井 |
| 独行代价 | 巡区夜间易失踪 | 单只游魂难大啃、易被清扫员顺手永灭 |
| 边界 | 城越亮、巡查越密，怪越难明盘 | 城提供「粮」；巢多在城的影子里——吃得到，又不太被天亮处的编制天天铲 |

**成巢机制（四句钉死）：**
1. **对仗**：人聚城求活；怪聚巢求噬。同一张地图上的两种聚集。  
2. **根丝**：两三只以上靠近会自发织半透明根丝，把地气、残名、游魂缠成一团——缠住了就是巢胚，散不开才叫成巢。  
3. **母体**：远处收名税时，成巢处像井口更好抽；分芽也爱从旧巢缝里冒（第2章河堤；卷1中后段中原大战亦是「井」）。  
4. **例外**：真要养大、产怪、啃史，须成巢或把楼盘歪成巢。高阶化人**很难正门混进稳区**——见下「哨卡」。

**和区划的咬合**：稳区=人的巢（反说）；巡区=人怪拉锯；禁区=怪巢占优、人要编队才进。清巢＝把怪的聚集拆掉，不让它继续当井。

### 哨卡与识别者（已定）
- 稳区出入口、枢纽站、跨巡区干道：**哨卡常开，盘查严**。  
- **每卡至少一名 B 级及以上「识别者」**（察名/感知向觉醒；编制名可叫听名员、识名岗）。  
- **能力**：能识破高阶化人（含会借名伪装的）；低阶靠影子口诀+仪器，高阶必须人感。A/S 级识别者多在禁区前沿与国防军配属。  
- **效果**：正门几乎筛掉「装人进城」的高危货；全球震（岳飞陨落章那种）后哨卡还会加码。  
- **漏洞**（给剧情用，不给怪开无敌）：地道、河堤、未设卡废线、哨卡腐败/调空、分芽从巢缝钻而非走路过卡——第2章河堤才炸得起来。  
- 陆铭进出稳区照样过卡；牌藏贴身，识别者扫的是「是不是怪」，不扫青铜废牌（除非他魂压乱晃被误抓）。

## 人类活动区与日常（已定 · 非末日）

### 为什么选「带伤正常」而不是废土末日
| | 带伤正常（本书） | 废土末日 |
|--|------------------|----------|
| 药费/房租/姐线 | 成立，日常压得紧 | 容易变成抢物资，药费戏发飘 |
| 瞒级、名录署、中介队 | 有衙门、有工种、有银行卡 | 编制难站住 |
| 独升式进化手感 | 城里当垫底清扫员最贴 | 更像求生文 |
| 鬼灭式化人魂怪 | 人群还在，才能「藏」 | 人少了，化人意义变弱 |

**结论：城还活着，只是带伤。** 回声计划撕开后各国都经历过乱，但十几年内（具体年代写作时钉）秩序重建——不是天天崩盘。

### 空间怎么切
| 区域 | 什么样 | 谁进出 |
|------|--------|--------|
| **稳区（主城核心）** | 电网、公交、学校、药房还开；**出入哨卡严**，每卡≥1名**B级识别者** | 普通人日常；陆铭租房、买药在这 |
| **巡区（城周/旧工业带）** | 巢点多；干道有卡，支线疏 | 清扫员主战场；中介队接单 |
| **禁区（重巢/未清净）** | 封路、探针、武装卡；识别者常配A级 | 国防军或高编队；E 原则上不派（炸档=误标/硬派） |
| **境外/他国巢带** | 各国自扫；边境严查英灵与察名/识别者 | 卷3 国际线 |

### 日常生活长什么样
- **还正常的**：上班上学、手机支付、租房电梯（坏了也能修）、电视新闻、药房窗口排队。  
- **不正常的底色**：新闻里清巢战报；小区偶发「忘名」隔离观察；入职/入学查觉醒与否；稳区边缘有根丝纹报警器。  
- **职业**：大部分人仍是普通人；觉醒者里少数人吃清巢这碗饭（像高危工种，不是全民战场）。  
- **物资**：药贵（魂伤科自费），不是抢最后一罐罐头；陆铭穷，是**阶层穷 + 药费穷**，不是末日穷。  
- **气氛**：更像「长期灾后的防疫/高危工社会」，不像废土抢车。

### 写作时怎么用
- 前两章已有的药房、老楼、银行卡、中介铁皮屋——**保留，就是正确调性**。  
- 禁止无故写成空城、变异植物吞楼、全民穴居。  
- 要冷就冷在：欠费单、药盒、误标的巢、队友拿 E 当耗材。

## 史威 · 永灭销史 · 华国续名制（全民共鸣 · 已定）

### 1. 英灵出场：亮「历史上有多强」
每次具名英灵**首次正式出场**（震出/攻略见到/战场请出），要用场面带一句读者能共情的史威——不是说明书堆砌，是别人的反应 + 一两记硬事迹：
- 例：沈承岳肩后名录亮「岳飞」，队里有人骂脏话又把刀握紧。  
- 陆铭侧第一次震出某影，也要用别人的反应或殿内一句硬话带出史威——并点明仍是影。  
- 本尊永灭的心疼留给销史戏；影淡了是另一层疼。  
- 随从级也可短亮：「明末亲兵，守过某城一夜」——垫高「有名」与陆铭「无名」的对比。

### 2. 英灵被魂怪永灭 → 相关历史消散
- **触发**：英灵战败于魂怪/母体侧，状态**永灭**（不是收进名录休息）。  
- **过程（要写出来， staged）**：  
  1. 当场：名录条目碎裂/变白；在场人舌头发木，想喊出全名时漏字。  
  2. 数小时～数日：公开史料、课本电子页、祠庙牌位上相关段落发糊、缺页、检索404；老人讲故事讲到一半接不上。  
  3. 未续名成功则长期：只剩残句、地名挖空、后人「总觉得有过这么个人」。  
- **范围**：以该英灵为核的事迹链（本人功业、专属典故）；不至于一次抹掉整个朝代，但**名将级永灭是国家级文化事故**。  
- **无名工匠**：本就几乎无公共史，永灭时世人无感；陆铭侧只觉得「连残响里的尺寸口诀也淡了」——反衬有名者永灭有多可怕。

### 3. 华国处理：召唤者续名制
华国名录署法定流程（他国可不同，卷3可对比）：
1. 英灵永灭后，**原召唤者**必须在时限内做**续名备案**：亲口述录/血指印/魂印，把英灵的**本名与关键事迹**刻进召唤者名下的「续名档」。  
2. 备案生效后：社会侧把召唤者登记为该英灵事迹的**活载体**——课本注「事迹今由某某续传」、祭礼呼召唤者名以召回记忆；史籍缺页会以续名档为权威补回一版（冷冰冰、官僚，但有效）。  
3. 召唤者若也死且无转续：销史加速，可能永久残缺。  
4. **待遇与枷锁**：续名成功的清扫员有抚恤/名分，也被盯死——等于背着一段国史走路；开战前队友会吼「别让他死，史还在他身上」。  
5. 陆铭与工匠：工匠无名，续名档几乎无字可录；牌是私货。他日后若有具名英灵永灭，会第一次被迫走续名——戏很重。

### 4. 和其他设定的咬合
| 设定 | 咬合 |
|------|------|
| 啃名 | 日常蚕食；永灭是一次性抽走 |
| 校对 | 可对抗啃名、协助续名档写全 |
| 试名牌 | 工匠为**拓影**而铸；称名浇范；与续名制同源异流（续史≠拓影） |
| 收服他国英灵 | 永灭则伤的是他国历史 → 外交核爆级 |
| 姐线/薇拉永生 | 反面：不靠续传，靠把人钉死在「永不散」——凯的歪路 |

### 5. 写作硬规矩
- 具名英灵**首出场必有史威**（短、硬、嵌场面）。  
- 任意具名英灵永灭：**必须写销史过程至少两拍**（当场 + 事后课本/人口）。  
- 华国角色永灭后：**续名手续或拒办/来不及**要入戏，禁止无声消失。

## 无名工匠（已定）

**周人**，铸铜，**受周公之命**探「名何以不散」——奉命匠人，**不是周公**。周公可被后人正常震取。真名全书不揭（造拓影之器者自隐其名，免得影与范黏在铸者身上）。

**造牌目的（已定）**：试名牌就是为了**复制别人的影**——无血脉者也能用名将之影守土，史不必只挂在单一血脉召唤者身上。周公要「名可拓、影可用」；匠人交出素面圭形牌与殿，自己不肯留名。

表层：清巢时不善砍，爱划纹；「别把名字随口许给听不见的东西。」  
第2章：他「称」退分芽 = **第一次把范烧活**（以己为助燃/校准）→ 永灭 → 活牌归陆铭。世人无感；陆铭只剩牌与尺寸口诀残响。

陆铭一度以为「谁清巢都能捡到」；后文打脸——会自动拓影的活牌几乎没有，他这块是烧活的那一块。

## 试名牌如何拓影（已定 · 工匠原设计）

> 人话：名要散的那一瞬间，牌当铜范，浇进去一道影；本尊仍可被咬灭，影是拓出来的模，不是把人偷走。

### 为何只能「将散」时拓
安稳本尊的名核钉在史与血脉上，范贴不上去。只有**名散临界**（将永灭、名核被啃松、逃名外溢）时，名气如熔铜可浇，牌才能拓。

### 拓影三条件（缺一不可）
1. **名散临界**：目标本尊将永灭或名核重创外溢。  
2. **近场**：持牌者在冲击半径内（余波扫到即可）。  
3. **活牌有空席**：英灵殿有空位；牌已在第2章被工匠烧活。

### 工序（正文体感）
1. 临界时逃名外溢，空气发苦、耳鸣。  
2. 圭形牌自行发烫，毛刺刺掌，像范要吃铜。  
3. 牌「称」住逃名一截——**不抽干本尊**，浇铸一道**影**入殿落座。  
4. 本尊仍可被咬灭 → 销史照常；影留下，或淡或哑。  
5. 持有者可无感；事后牌凉了、多怪梦，或殿里多一人。

### 拓出的影服从总规
当前战力跟持牌人；上限=本尊历史档；可与他人同名并存；不能对平安无事的S隔空复印；本尊已销到无残名可称则极难再拓（岳飞场须卡将散瞬间）。

### 为何未普及
周时只做出个别活牌；门阀忌惮无血脉用影；匠人隐名，法不进公文。名录署劣版探针只会称空，**不会拓影**。陆铭误捡失传活范。

## 母体为何不直入人类社区吸魂（已定）

若母体能整具钻进稳区挨家吸，带伤正常社会与哨卡全废。限制钉死为**不能 / 不肯 / 不划算**三层：

| 层 | 原因 |
|----|------|
| **不能（体量与层位）** | 母体沉在魂界与旧节点绞杀处，体量远超街巷；稳区「活人名压」极密（亿万人的完整名字叠在一起），整具挤入会被名压撕薄、暴露坐标。她能做的是**抽税、渗漏、分芽**，不是变身市民排队。 |
| **不肯（识别与火力）** | 稳区哨卡遍布 B 级识别者 + 驻卡英灵；母体投影一浓，识别者会群体耳鸣/空名爆表，国防军级会倾巢。卷1中后段一个分芽杀S已全球震——本体现身等于把自己送上总攻桌。 |
| **不划算（寄生更肥）** | 成巢当井、远程收名税、分芽探路：人还在产「名」、城还在转，细水长流。直砸稳区会逼各国联手、人口逃散，井反而干。 |

**她实际怎么吃：**  
巢井抽税 → 游魂/化人在巡区猎食 → **分芽**从巢缝短促探入（河堤、战场）→ 极罕见的稳区渗透靠漏洞，不是本体散步。  

**和薇拉声：** 声可穿梦、穿直播缝（岳飞陨落章），人不等于母体到场；声是钩子，芽是手，本体是根。

## 开局三章节奏 · 试名牌引出（已定 · 减负）

### 地名
中原失土 = 汴京故土巡区（**不叫金地**；金=金朝）。

### 开局减负原则
1. 前三章情绪落在**陆铭**：养姐、炸档、光杆善后；不抢戏给电视名将。  
2. **岳飞陨落不放第3章**——等主角有牌、有独清、读者认他了，再砸同分芽杀S（约卷1中后段）。  
3. 第3章设定只保留「没英灵难结清巢赏、牌先藏着」；**续名/销史完整科普推迟到陨落章**。  
4. 中原战在开局只作**顺风背景**（打得顺、还在收），不写成当场翻车。

### 三章分工
| 章 | 内容 |
|----|------|

## 写作注意

- 战场单位永远是**巢穴/魂怪/清巢**，禁止写成进本、刷门、副本重置。  
- 魂怪：可化人、不怕阳光；发现以觉醒者魂感/察名系为主；真形灰膜细牙根丝；噬魂名。**禁止丧尸写法**（尸潮、传染变尸、当丧尸描写）。  
- 日常：**带伤正常**（稳区生活 + 巡区清巢）；禁止无故废土化。  
- 成巢：**人聚城、怪聚巢**；根丝织井，母体好抽——需要时用闲话带一句即可。  
- 城防：**哨卡严，每卡≥B级识别者，高阶化人也能识**；怪走缝不走正门。  
- **母体不直入稳区逛街吸魂**：名压+识别+寄生更肥；吃靠巢井/分芽/化人。  
- **本尊**永灭必写销史；陆铭侧写清收的是**影**。  
- 陆铭上场：当前跟自己，上限=本尊档；先E手感再拉高。  
- 独升只借：进化过程、国际关系、编制组织。  
- 无系统窗、无商城；英灵殿是冷殿席位。  
- 工匠真名不揭；周公命匠非周公。  
- 华佗绑姐线；诸葛亮绑交底与终局调度。  
- 收影须同场因果（前两席S将死；其后重伤/特许等）；禁止无因果入殿。  
- boss与陆铭（影强度）**同步变强**。
