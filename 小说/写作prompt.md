---

你在写或改中文小说。目标：读起来像人过日子说话，不像 AI 范文总结。

## 硬规则

1. **话捋直、说完整**：旁白和对白都把意思说清楚；禁止「句号雨」，也禁止电报式蹦词（「退。」「够。」「看。」）。人物可以少言，但开口就要让人听懂。
2. **别排比、别对仗腔**：禁止一不小心排比、对仗、半截口号并列；禁止段末金句、人生道理收束。
3. **别「先…后…再…」总结**：禁止把领悟排成步骤或方法论。
4. **能开口就别转述**：该说的写成对白；禁止旁白代说「他说要……」「他明白……」。
5. **意思嵌在场面里**：用动作、对话、物件带出感受；不另加抽象点评。
6. **对白要像嘴里冒的**：口语、具体、可接话。**「像人说话」≠「越短越好」**——宁可多半句把因果说清。
7. **旁白只干脏活**：交代时间地点动作即可；不替读者提炼主题。
8. **设定词先讲清再简称**：专名第一次出现必须用人话落地，再简称。
9. **背景先让人站稳**：章首别堆专有名词串烧；科普用解说/广播/问话把话说全。
10. **关系、因果、情感写明**：谁与谁什么关系、续名/战死怎么接、该懂的家国心——用完整对白和可见过程写清，禁止谜语式点到为止。

## 反面（禁止）

```
「够。」「看。」「退。」「短。你听我的——」
催就催。人还在，巢还接得上。
根丝刺的是名。投影碎白。
沈承岳，S级，英灵岳飞，中原失土——公文写汴京故土巡区——
没什么仪式感，就是过日子。
```

## 正面（气味）

```
「先压住了，撑不了多久。你听清楚：立刻出巢，听见它说话别接话，也别回头许愿。」
「母体进不了城，会从巢缝里伸出一小截活的来吸——编制叫分芽。」
「我是岳家后人沈承岳。岳飞的名字我续上了……剩下的疆土，交给后来的人。」
```

## 改稿自检

- 有没有电报式蹦词？意思说全了没有？
- 有没有短句排比、对仗腔、段末金句？
- 有没有「先/后/再」式领悟清单？
- 本该出口的话是不是被旁白吞掉了？
- 设定/背景/关系/因果是否先让人站稳、写明白？
