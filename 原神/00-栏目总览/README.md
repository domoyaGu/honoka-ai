# 蒸汽鸟报 · 老登观察室

用夏洛蒂做固定出镜记者，采访原神角色，演绎**老玩家日常**：每日打卡、地图躺平、主线偶尔推、深渊还在打。

## 定位

| 项 | 内容 |
|----|------|
| 受众 | 老登 / 上班族旅行者 / 没空肝图但仍在玩 |
| 形式 | 15～25 秒 AI 短视频，采访实录风 |
| 固定栏目 | 夏洛蒂 + 旅行者（主受访）+ 派蒙（吐槽）+ 每集客串 1 人 |
| 更新节奏 | 建议一周 7 集，可先周更 3～4 条练手 |

## 分集目录

| 集 | 文件夹 | 标题 | 核心梗 |
|----|--------|------|--------|
| 01 | `01-上班族旅行者` | 您今天肝原神了吗？ | 委托→树脂→下线 |
| 02 | `02-新地图收藏了` | 新地图亮了吗？ | 打开过 / 真大 / 明天再来 |
| 03 | `03-深渊是一种信仰` | 您有什么爱好？ | 通深渊，等下期 |
| 04 | `04-主线只狗剧情` | 您还看剧情吗？ | 周末一次性过；上周也这么说 |
| 05 | `05-树脂满了会慌` | 树脂满了您慌吗？ | 满了慌，清完一天结束 |
| 06 | `06-仓库很强人已躺` | 常用几队？ | 柜子金闪闪，上场就一队 |
| 07 | `07-版本夜看完就跑` | 更新夜您怎么过？ | 动画→每日→打开新图→下线 |

## 每集文件说明

- `脚本.md`：完整分镜、提示词、大字、封面、剪辑备注
- `台词.txt`：纯台词，方便直接丢 TTS

## 统一制作规范

1. **硬约束：视频生成必须依据官方立绘**  
   - 参考图只使用 [`角色定妆参考/`](./角色定妆参考/) 内文件（祈愿立绘 / 头像）。  
   - 生成时走 **reference / 图生视频**，禁止仅靠文字臆造角色外形。  
   - 某角色缺图时先补进该文件夹，再开生成；不得用「长得像」的替代脸。  
   - 表演可改（疲惫、吐槽），发色、服装、标志道具以立绘为准。
2. B 站投稿勾选 / 声明：**使用人工智能合成技术**。
3. 转场以硬切为主，少特效，越像「街头采访」越好笑。
4. 片尾可统一口播收束：`蒸汽鸟报，我们明天见——如果你还没让树脂溢出的话。`（可按集微调）
