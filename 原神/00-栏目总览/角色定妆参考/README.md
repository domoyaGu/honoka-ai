## 视频生成规则（强制）

1. 出任何一集画面前，先把本集出场角色对应 PNG 当作 **reference_image_paths / 首帧参考**。  
2. 禁止纯文生视频瞎编脸；文字提示只补动作、镜头、情绪，不重写外形。  
3. 新角色先下载官方祈愿立绘进本目录并命名清晰，再生成。  
4. 派蒙若仅有头像，优先补全身官方图后再做含派蒙的镜头。
