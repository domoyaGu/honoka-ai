## 建议顺序（先文档，再流式）

### 1. 后端文档列表 `GET /docs`

文件：`apps/api/src/routes/docs.ts` → `docsRouter.get("/")`

**【你来写】**

1. `readdir(UPLOADS_DIR)`，跳过 `.gitkeep`  
2. 对每个文件 `stat`，拼出 `{ id, name, size, uploadedAt }`  
   - `id` = 磁盘文件名  
   - `name` = 展示名（可去掉前面的 `时间戳-`）  
3. `return ok(res, items)`

提示：防目录问题——只信任 `path.join(UPLOADS_DIR, name)`，不要用用户乱传的相对路径。

手测：`curl http://127.0.0.1:8788/docs`（需先 `npm run dev:api`）

---

### 2. 后端上传 `POST /docs/upload`

multer 配置（存哪、文件名、只允许 md/txt）**已搭好**，你主要看懂并写好回调里的成功响应。

**【你来写】**

在 `upload.single("file")` 回调里：

- 有 `err` → `fail`  
- 没有 `req.file` → `fail`  
- 成功 → `ok(res, { id, name, size, uploadedAt })`

字段名必须是 **`file`**（和前端 `FormData.append("file", …)` 一致）。

---

### 3. 后端删除 `DELETE /docs/:id`

**【你来写】**

1. `id = path.basename(req.params.id)`（防 `../`）  
2. 禁止删 `.gitkeep`  
3. `fs.unlink(path.join(UPLOADS_DIR, id))`  
4. `ok(res, true)`

### 5. 后端 Mock SSE `POST /chat/mock-stream`

**【你来写】**（按注释骨架填）
